# Security reporting

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/stephenlclarke/elite/security/advisories/new). Include the affected commit, steps to reproduce and impact. Please keep credentials and personal commander data out of public issues.

Security fixes target the current `main` branch. Pull requests run coverage, sanitizer and memory leak checks; main-branch analysis also runs SonarQube. These checks cover the exercised paths and do not guarantee the absence of defects.
