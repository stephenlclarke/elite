# Agent Rules

If `~/.agents/AGENTS.md` exists, read it and follow it.

Use Swift 6 actor isolation. GameRuntime owns simulation state; AppKit stays on the main actor. Run `make ci` for coverage, sanitizer, and leak gates. Publish SonarQube analysis only from a committed main branch with the exact commit SHA as projectVersion. README media must be generated by the game renderer with `make readme-media`.
