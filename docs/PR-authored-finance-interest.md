# Add a capped, explicit simple-interest finance product

The existing native finance provider gains `simple-interest-v1`, gated by `finance-interest-simple-v2` and `mission-calendar-v2` alongside its existing finance/story/durable capabilities. Each loan declares `[loans.interest]`: integer `rateBasisPoints` (1-10000), integer `periodSeconds` (1-31536000), `rounding` (`up` or `down`) and positive lifetime `maximumInterest` in native tenths of CR. Principal plus the maximum possible interest must fit the existing native cash bound. Unknown nested terms, unsupported combinations and missing terms are refused. `fixed-principal-v1` without interest remains a supported interest-free product. The new executable [original example](mission-packs/finance-interest/README.md) explicitly declares a 200.0 CR loan, 10% daily simple interest rounded up to 0.1 CR and a 100.0 CR lifetime interest cap. It is not GSE or a complete financial campaign.

Periods are anchored to the accepted Borrow receipt's calendar timestamp. At a completed period end, apply the declared rate to then-outstanding principal, rounded per period. Unpaid interest never earns interest. Before repayment, assess all elapsed completed periods since the last receipt; then allocate cash to interest first and principal second. A partial payment between boundaries changes the principal used at the next boundary without restarting the clock. No per-second proration, automatic cash debit, wall-clock offline time, deadline or global fee is introduced. Lifetime assessed interest never resets after repayment, and paid or declined records never revive.

The pure balance projection computes the completed period index from real calendar seconds. Between financial actions principal is constant, so catch-up is `missedPeriods * roundedPeriodInterest`, saturated at the remaining lifetime cap before multiplication. Both period count and all native monetary inputs are bounded; invalid or backwards time refuses. This is constant work per record even after a trillion missed periods. No actor, scheduler, per-period loop or new Game/Commander storage layer is added.

UI and Lua reads project current principal, unpaid interest, lifetime assessed interest, completed periods and explicit rate/period/rounding/cap terms without mutating receipts, cash or the calendar. Page facts and captured quotes include the projected balance. Confirm rejoins the original owner/resource/epoch/native station/ledger/token/parent checks and rejects a changed accrual projection. Only the existing atomic durable command appends an assessment/payment receipt and publishes cash/ledger effects. Current receipts contain required before/after interest, newly assessed interest, lifetime assessment and completed-period facts; validation independently replays every receipt's arithmetic from immutable terms and its original borrow time. Current-format roundtrip retains them; no predecessor migration or compatibility alias is added. Existing monetary/numerical bounds, receipt-count limits, native arrival proofs and candidate rollback remain authoritative.

Ten focused methods (sixteen cases) are authored for exact boundaries, rounding, capped huge catch-up, numerical refusal, malformed/hidden terms, explicit decline, partial principal and interest-only payments, no compounding/cap reset/revival/replay, read purity and same-resource stale accrual, failed native writer rollback followed by exactly-once payment, terminal-parent/current-format persistence, forged assessment and actual market-funded partial payment. Controlled arithmetic/calendar fixtures are labelled as such. A separate native countdown test starts from an explicitly controlled mass-lock-free position, uses genuine launch, hyperspace admission, physical countdown, fuel debit and native arrival/calendar adjustment, then checks increased projected interest with unchanged cash/receipts. It is not a claim of a flown station-departure journey. Existing finance and its native quote/save regressions remain relevant.

Author checks are strict Swift formatting, Markdown lint and whitespace only.
