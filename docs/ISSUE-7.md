# Simplify MacBook controls and showroom navigation

Players report inconsistent exit keys, too many context-dependent bindings, references to keys absent from a built-in MacBook keyboard and an unintuitive ship browser. The retired docked system-data key 6 should open the showroom; charts 4/5 already own its planet facts. General controls should say mission contacts / mission dialogs, reserving the campaign name for campaign content and its guide.

Make the basic pattern predictable: numbers for areas, arrows to move, Return to choose, Escape for nested Back and K for help. Separate search input from shortcuts; preserve sensible return paths and clear held flight inputs on transitions. Move escape-pod launch away from Escape and energy-bomb detonation away from the new targeting Tab action. Provide discoverable native menus and clickable browser actions so secondary letters need not be memorised. Simplify basic keyboard flight and document actual MacBook Delete/paging combinations.

Inspect the real showroom before changing it, then exercise finding, inspecting, pinning/comparing, profile switching, scrolling, returning and exiting at ordinary and wide sizes.
