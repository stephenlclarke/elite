# Central equipment runtime integration in progress

This isolated source checkpoint incorporates the immutable physical inventory API and sealed loaded-component validator. Its explicit runtime catalogue maps saved equipment keys to typed slots, component definitions and actual hull masks. The Commander migration adapter adds optional-backed inventory, history, salvage custody and a version marker; owner and hull UUIDs come from the inventory itself. It preserves actual historical component statistics, known reward/XYZZY provenance and replaced devices as held items. Unknown legacy acquisition receives grandfathered entitlement without fictional paid receipts. Read access allocates no identities, and repeated initialization leaves existing state untouched. Full purchase-history validation reuses the existing graph validator.

Independent source review corrected two migration boundaries: native hull jump reach remains outside the transferable navigation component, and an old XYZZY flag cannot relabel ambiguous items as grants. Only an explicit grant mutation supplies grant provenance. Eleven migration regression methods and seven work-tool methods now pass in the focused 18-test run on `3958077a7fa1d066dc586654565b9a9e156a8971` (8.328 seconds test time; 33.8753 seconds command time). The optional TOML work-tool support is explicit for Cobra and Liberator; other hulls fail closed. A physically fitted separate Mining tool uses attributed rock damage and finite energy/heat/cooldown without replacing any of the four combat laser facings or the Cutter. Occluding ships/stations are not shot by this adapter. G2's source-reviewed guards refuse nonfinite resources and stale, missing or depleted authoritative rocks before attack/cost. Assertions evaluate mutating calls before passing results into Swift Testing macros. The held-Mining fixture now explicitly fits Pulse; a complementary legacy-derived Mining front fixture verifies preservation. Raw failed compile/fixture attempts and the corrected pass remain in focused evidence. Production save bytes are unchanged. This is focused validation; renderer fingerprints and full integrated acceptance remain pending.
