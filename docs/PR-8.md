# PR #8: TOML missions and signed macOS release

The Constrictor hunt, Thargoid plans delivery and Blackjack's Bullion now load their campaign stages, conditions, dialogs, clues, encounter bindings and rewards from bundled TOMLs. Commander > Install Mission Pack accepts supported external content without rebuilding. The optional Lave courier example reserves one tonne and pays 50 CR exactly once at Zaonce.

The engine validates IDs, versions, capabilities, references, conditions/actions and file bounds; it rejects scripts, unsafe file types and unsupported mechanics. GameRuntime owns installation and simulation changes. Transitions commit the commander, payloads, stage and receipts atomically. Read adapters map all legacy naval/Blackjack stages without rewriting old saves or replacing unique targets. Missing or changed packs suspend saved progress and cargo. Version 1 grants only real flag-based equipment; lasers, computers and stock changes need dedicated fitting primitives. Failed terminal stages retain their actual milestones, cannot restart and cannot trigger success rewards. External target spawning, repeatable contract instances, calendar time, cabins, crew and storage remain unsupported; researched packets stay queued.

The app exposes installed/suspended campaigns in its Gallery, scrolls long dialogs and lists reserved parcels in inventory. The window now presents a completed Retina frame atomically; native review raises the window before accepting captures, because background captures can be incomplete. Status/inventory use contextual Back/help footers consistently. Static-analysis cleanup removes nested conditional expressions and an unused parameter from the previous shipyard change.

A Makefile-backed distribution workflow builds arm64+x86_64 Release slices, packages exact resources/notices and signs with Developer ID and the hardened runtime. It verifies the extracted ZIP, records its source checkpoint/checksum and separates signing from notarization. The repository includes releases/macos/Elite-1.1.0-universal.zip (4,496,019 bytes), its SHA256 and manifest. It is built from committed source bd0cf679fd9ca118aa7f84621a1e67287a135e03; the later artifact commit is deliberately not called its own source. Both Mach-O slices target macOS 14.0. Extracted strict/deep signature, Developer ID authority, hardened runtime, secure timestamp, architecture/resource parity, CLI probe and native Gallery launch passed. No notarytool keychain profile was supplied: notarized is false and Gatekeeper reports Unnotarized Developer ID.
