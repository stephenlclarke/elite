# Integrate the reviewed original fleet staging compiler

Add the Python 3.11+ standard-library compiler at `Tools/compile-original-fleet.py` and its focused tests at `Tools/tests/test_original_fleet.py`. Generation preserves supplied specs and hulls byte for byte, joins only exact matching IDs, and emits a deterministic readiness inventory. Missing geometry, unsupported policies, metadata, unit contracts and texture adapters remain explicit dependencies. The compiler refuses overlapping paths, redirected output roots, nonempty output trees and oversized inputs/outputs. Check mode verifies the staged inventory without activating runtime data.

Run `python3 -B Tools/compile-original-fleet.py --input-root /path/to/approved/proposal --output-root /path/to/fresh/staging`; use the same command with `--output-root /path/to/frozen/staging --check` for integrity checking. Focused tests use `python3 -B -m unittest discover -s Tools/tests -p 'test_original_fleet.py' -v`. The maintained tool is independent of the game's native build and renderer workflows.

The isolated MBA run generated 171 specs, 94 preserved original hulls and 94 joins, leaving 77 missing meshes. All records remain runtime-inactive. The staged payload stays remote and immutable; no data, catalogue, loader or gameplay change is included here. The supplied handoff at `/tmp/l337-fleet-handoff-20261019/README.md`, `result.json` and `readiness.json` records loader/profile/unit/policy/texture gaps and distinguishes original generation evidence from later source fixes.
