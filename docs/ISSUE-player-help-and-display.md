# Context help and XYZZY display choices

## Requested behaviour

Players need a key guide for their current activity, plus a secret selector for white wireframes, coloured wireframes and shaded panels. New normal games should begin as Commander Jameson; entering XYZZY should create Commander Clarke's fully equipped Cobra Mk III. Unlimited fuel and hyperspace distance belong in XYZZY rather than the Executive paused @ shortcut.

## Acceptance

- Open context help with K, Command-K or the Help menu, page with arrows and return with K, Return or Escape.
- Pause the simulation while help is displayed and show relevant flight, station, trading, equipment, chart, pause, title/demo and secret keys.
- Use XYZZY 0 to cycle the three ship display modes; retain 4/5 for unlimited fuel/distance.
- Save the selected style and load older commanders with white wireframes.
- Keep Jameson's standard equipment for normal starts; fit Clarke's maximum hardware without deleting progress, cash or cargo.
- Retain the original-style font and number-key navigation.
