# Render planet terrain and weather from actual economy

PlanetPreview now retains a resolved PlanetPalette from the actual inspected StarSystem.economy. PlanetAppearanceProfile defines all eight economy classes with ocean, land, highland, vegetation, cloud and atmosphere colours; sea level, polar ice, vegetation strength, cloud coverage/opacity and haze/rim parameters. These are game art choices. Stable identity variation adjusts ocean/land brightness, sea level and ice without consuming simulation randomness. Government is not a profile input.

Both CPU and GPU use the same profile for coastlines, elevation-dependent vegetation and highlands, cloud coverage, surface haze and the premultiplied atmospheric rim. Existing illumination, rotation, framing and terrain generation remain unchanged. Both single-frame caches include the full resolved appearance; the eight-entry terrain cache and GPU terrain uploads remain identity-only. A named uniform enum supplies both the Swift upload slots and the once-compiled Metal source indices. No new concurrency escape or per-frame terrain generation is introduced.

Regression source covers all eight distinct profiles, deterministic appearance, government independence, unchanged identity/terrain across economy changes, actual weather coverage, profile variation between identities, image cache invalidation and restoration, atmospheric alpha differences, and named uniform layout. Existing GPU/reference comparisons now select all eight actual economy classes, retaining colour error limits. Alpha tolerance changes from exact equality to at most one byte because the economy-specific rim factors include non-binary fractions. This suite still requires ELITE_PLANET_GPU_EXPERIMENT=1.

Only source formatting, strict Swift formatting lint, scoped Markdown lint and whitespace checks ran. No compiler, typecheck, tests, native process, media or CI ran in this worker. Coder 1 owns integration, CPU/GPU execution, native visual/performance acceptance and required make ci gates. No planet save schema, ring policy or gameplay economy generation changes are included.
