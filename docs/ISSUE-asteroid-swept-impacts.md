# Moving asteroid debris needs actual native impacts

Phase-one custody and ray occlusion do not make moving debris dangerous to player hulls, NPC resources or station resources. The required continuation must prove real swept geometry contact, exchange finite equal-and-opposite momentum and apply effects through actual native resource authorities. A sample that misses thin geometry cannot establish absence; an unproven query must retain physical state.

The current first source slice supplies actual pre/post movement capture, a continuously covered native hull contact query and player/ordinary NPC effects. Station contacts intentionally refuse until the separately authorized translational station custody is implemented. The full feature and campaign remain open. No source-only test is runtime acceptance.
