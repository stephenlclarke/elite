# Observe finite native title and credits runs with the existing frame observer

The opt-in command is `Elite --profile-startup-frames /absolute/new-output-directory SOURCE_SHA title|credits FRAMES`. The source must be a lowercase 40-character SHA; frames must be 2 through 120. Title and credits initialize separate fresh normal commanders at time zero and run in a visible 768-by-768 compact AppKit window. They do not load a previous commander, launch, inject flight inputs, freeze the startup clock or prepare the planet GPU backend. Existing normal and planet-mode entry points retain their previous behavior.

The existing GameView.draw timing records and frame observer are reused. Startup samples are tagged with the requested scene; report metadata includes the requested distinct draw count, declared source and actual executable hash. Presentation, drawing, processing, intervals, repeated draws and undrawn/coalesced submissions remain separate. Completion requires the requested number of distinct observed draws in the same visible key-window scene. A scene change, lost window, cancellation or 120-second observer bound produces an incomplete report and unsuccessful exit. Startup does not take a screenshot or export media. Credits retains its real transition to title; the observer does not extend it artificially to satisfy a sample request.

The report is candidate observation only. The existing rounded 60-Hz interval estimate is not a new acceptance threshold, physical scanout measurement or performance claim. Title/credits samples do not satisfy planet flyby geometry checks and are labelled independently. No LOD, caching, geometry simplification, pixel policy or rendering algorithm changes are included.

Changed paths are limited to EliteApp.swift, PlanetFrameProfiler.swift, StartupFrameObservationTests.swift and these paired notes. Focused tests cover argument validation and output noncreation on refusal, exact title/credits fresh-scene initialization and distinct-draw completion, plus preservation of ordinary/planet observer selection. Strict Swift formatting, Markdown lint and source-scope checking precede independent bugs/performance/style review and owner focused DEBUG execution. Compiler, unit and native jobs are initially unrun until the shared executor grant. A later optimized product-only build and actual native run remain integrator work; no repeated Release test-target build, media export, full CI, frame-budget or playable acceptance is claimed.
