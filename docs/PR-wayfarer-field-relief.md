## Implementation

One pinned production pack and immutable typed ScriptInstance leaf bind each of the two finite native consignments to its exact originals, frozen full-route quote, source contact, installation and separate current receiving engineer receipt. Native stock, material IDs, sockets, physical cargo and recharge remain owned by the unchanged native utility model. The existing accepted contract occupies the shared service allowance; no second cargo claim or stock ledger is added. No advanced qualification, hazard premium or deadline is offered.

Collection and installation never pay. Current engineer reception uses the original frozen quote and existing checked contract settlement once, then commits the actual normal ScriptCompletionReceipt, production execution pin, existing field-relief clue and dependent completion notification in that same protected durable transaction. The permanent first clue remains through later repeats or target loss. No source identity, clue identity, query union or clue-progress requirement is added.

Native replacement updates the mission before validating the same candidate. Writer refusal restores original property, instance, credits and clue together. Held escape/fatal loss fails unpaid; source return abandons unpaid and retires originals. Actual target destruction fails unpaid work without restoring held or installed material. A surviving held batch may later return without rewriting its failed completion. Station-installed property survives player ship loss; a completed mission and clue survive target destruction. Publication records actual station death and reconciles the mission on that same candidate; the actor tail retries autonomous target-loss publication after writer refusal.
