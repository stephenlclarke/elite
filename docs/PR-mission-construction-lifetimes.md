# Separate source checks, parts construction and finalization lifetimes

Source construction first completes the unchanged legacy comparison in a non-inlined helper. Each sorted actor's original identity/body-read guard then completes in another non-inlined helper returning the same selected actor, before its template is constructed. This removes those guard temporaries from the source caller's nested construction lifetime. The same fresh current-Game dictionaries, original instance ID/digest, legacy values and selected actor remain the only inputs; prepared-condition validation and append still follow each actor's complete template.

Template construction now builds parts and maximum energy before entering a separate bounds/canonical-body finalizer. Both phases are private and non-inlined, with an immutable checked-Sendable parts value between them. Full NPC-fit validation still precedes construction. Measured mesh construction likewise completes the original installed-hash/model/full-ShipDesign-equality/validity guard before a separate non-inlined transformation phase reads raw mesh and applies the original transforms. The existing fit value now explicitly conforms to Sendable. No phase captures Game/Commander, exposes authority, caches results or suspends.

Source correspondence rejoins the original guards, parts/finalization and geometry-validation/transformation bodies. Apart from explicit parameter substitutions for the same instances dictionary, instance ID and pack digest, each old body is recovered byte-for-byte; inverse replacement recovers the whole original file. Component identity checks still immediately precede their own geometry construction, every actor completes before the next starts, and condition/resource/finite geometry checks retain their original order and error text. Native authority, staging, rollback, publication and tests are untouched.

Strict Swift formatting, scoped Markdown lint, whitespace checks and source correspondence are the only author validation; no build, test, debugger, native, GUI, renderer or probing job runs. G1 independently reviews/integrates once, compiles once, checks actual phase boundaries and first reruns only the same two anchor cases before the 83-method/158-case acceptance selection. Run 463's passing timers remain qualified without repetition. This source patch establishes no runtime pass, emitted-frame reduction, aggregate stack peak or full-CI acceptance.
