# Identified salvage owner return

## Motivation

G09 requires a finite, owner-identified recovery journey from the actual Avenor depot to the Renas exterior wreck cradle and back. Ordinary commodity scooping cannot represent serial custody, protected hold reservations or unpaid return of a surviving original after loss.

## Required behavior

The depot grants permission for PELL-01 and PELL-02 and reserves two tonnes. Native physical pickup fills those reservations; both originals returned to their owner pay 880 CR and award the family trace once. Cancellation, destruction, fatal hull loss and Escape Pod use preserve finite source accounting and never replenish originals. Writer refusal must permit a single durable retry without rolling back attained physical motion.

## Scope and compatibility

Implement the approved G09 complete journey and approval JSON in docs/gameplay-design/approved. Preserve existing collector geometry, tool requirements and unrelated mission collision policy. Schema 51/52 must independently preserve genuine prior-family claims through strict schema lowering. No migration, renderer asset change or new player control is required.
