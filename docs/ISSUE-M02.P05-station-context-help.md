# M02.P05.station-context-help: truthful docked shortcuts

## Problem

The station help page labels equipment, market trading and ship exchange the same way at the main orbital station, RRS waystations and RRS headquarters. The service policies already refuse shops and trading at the latter docks, and ship exchange requires a main station. The guide does not identify that distinction.

## Scope

Project the existing dock name and actual equipment, market and exchange availability into the station help page. Keep every screen shortcut, launch, chart, Status, Inventory and Back action. Do not change service permissions, quotes, equipment, cargo, mission state or navigation dispatch.

## Acceptance

- Main-station help retains its current shortcuts.
- Waystation and headquarters help name the current dock and explain unavailable services.
- One unavailable service does not hide unrelated available services.
- Flight help retains its existing destinations regardless of dock-only capability values.

This is a component feature from the [completion ledger](COMPLETION-LEDGER.md), not a gameplay-journey or release acceptance claim.
