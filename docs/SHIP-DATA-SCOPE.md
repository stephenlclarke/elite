# Ship data scope

All ship research remains in scope, including Frontier-derived ship capabilities, the 158 numeric refit profiles and the docked shipyard design. Mission exclusions do not remove ships, equipment capabilities, alien records, source mappings or provenance. Preserve the complete ship data when updating research catalogues or implementation filters.

The independently maintained local `docs/research/implementation-scope.md` controls mission implementation eligibility. Its v4 station-handoff policy replaces retained planetside stages with explicit station transactions while preserving separately excluded Frontier and Operations catalogues; it does not remove ship data. It does not mean every researched campaign is already playable. The current native Mission Gallery describes the two implemented BBC Executive naval missions (Constrictor Hunt and Thargoid Plans) and Blackjack's Bullion.

The docked showroom now loads 167 authoritative per-ship TOMLs, each containing its numerical design. It retains 74 sourced models and adds 93 original project designs. The 158 flyable adaptations support actual hull exchange with compatible equipment/cargo transfer and native game comparisons. Nine display objects cannot be purchased. Cabin fitting and persistent surplus equipment storage remain future work; incompatible transfers are blocked without loss. See [ship definitions and limitations](SHIP-FILES.md) and [the generated animated catalogue](SHIP-CATALOGUE.md).
