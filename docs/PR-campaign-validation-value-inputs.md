# Validate campaigns with fresh campaign-only inputs

Campaign validity builds a private checked-Sendable dictionary/clock view from the same borrowed engine and iterates its dictionary indices in the original values order. Each selected parent is projected in a non-inlined read boundary into an immutable checked-Sendable member owner containing only actual campaign fields. Child/owner lookups use the same boundary, so full ScriptInstance temporaries return before core validation. The child loop and binding validator receive member references and the small engine view, rather than full ScriptInstance/ScriptEngineState arguments. No projection is cached, encoded, externally supplied or accepted as native authority.

The original scope, child and owner bodies remain in order with the same shared duplicate-ID set. Child equality still compares the complete saved ScriptChildBinding; definition matching retains all original pin fields. Parent depth/root scalars are exact projections of the same saved parent binding. Root-parent absence and root existence remain two separate ordered predicates with actual dictionary reads; acknowledgment and all cause/committed/current time/revision guards remain intact. Empty children still execute the same zero-iteration loop, while every populated child runs every original check. The existing ScriptInstance definition-matching API remains for command/gallery callers.

Correspondence reverses only same-field projections and lookup boundaries to recover all original binding/scope/child/owner predicate bodies, checking constructors and coordinator order separately. Dictionary indices select the same immutable `.value` elements as the prior values traversal. Native receipt/commit/rollback, ScriptMissionState/ScriptDirector, writer/encoding, stored fields/schema and tests are unchanged. This removes whole-record argument/storage ownership from the core path rather than adding an empty-collection guard or another equality wrapper.

Author checks are strict Swift formatting, Markdown lint, whitespace, caller inventory and source correspondence. No author build/test/native/GUI/debugger/disassembly/profiling job runs. G1 independently reviews/builds once, first reruns actual 503 and then applicable existing populated/malformed campaign cases. Retain the original EMP 502 and other passing scopes on their qualified source; no author rerun is performed. Sufficient runtime stack margin and emitted allocation behavior remain unqualified until execution.
