# Canonical equipment issue and ammunition transactions

Add pure sealed providers for mission equipment admission, own-issue fitting, original returns, loan release, standard missile loading and finite or virtual consumption. They pin complete transaction facts, preserve exact device identities and legacy metadata, and produce one inventory revision for each actual transaction. Unlimited ammunition leaves the inventory unchanged.

A read-only settlement projection uses the same restoration planner as quote and apply, allowing trusted adapters to derive budgets from actual proposed items. The runtime must stage issue records, resources, events and projectile effects before publishing the returned candidate.

Targeting-core replacement refuses a strictly lower existing targeting tier on both admission and refitting; explicit equal-tier replacements remain allowed. Capacity exemptions use one shared predicate over actual item provenance, canonical foundation policy and fitted shield, energy or navigation slot. An issued copy of the same basic node and a purchased basic targeting computer retain their ordinary costs.
