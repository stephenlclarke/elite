# CR-10: Surviving NPC rebindings retain retired threat addresses

The original claim that unlimited new NPC deaths grow crime history was withdrawn: ordinary logical NPC records, including terminal records, are capped at 128. A narrower actual runtime regression now demonstrates 24 persisted attack windows from 24 nonlethal attack/cull/rebind cycles of one surviving logical NPC in the same visit. Logical and living populations remain one, but each accepted physical rebind receives a fresh scene identity. Old crime windows were never reconciled.

Preserve logical threat continuity without retaining every retired physical address. Reconciliation must retain self-defence, first-aggressor and discharge evidence, frozen live-missile launch judgements and original damage attribution, while keeping existing death replay protection. Do not simply discard threats on culling. Implementation and validation: [handoff](PR-CR-10-survivor-threat-bindings.md).
