# Gate and complete the ordinary Crimbo lifecycle

## Motivation

The ordinary convoy needs actual native launch, arrival and departure callers. A decoded registry alone must not activate admission, orbit steering, traffic exclusions, defence or mission facts before the supported save reader has validated its owner, world joins and durable publication path. Travel must move original snapshot ownership before clearing the ordinary ledger, and returning must preserve spent resources and original logical keys.

The galactic-jump transaction also called the public arrival wrapper, which catches restore failures. The enclosing jump could therefore publish consumed hyperdrive, changed galaxy and refilled fuel after arrival had failed. The actual throwing arrival implementation must remain inside the same outer candidate.

## Required behaviour

Use one ephemeral Game readiness gate, default false and absent from Commander/Codable/UI state. G1 alone enables it after actual supported version-28 validation and durable native readiness. Gate every automatic Crimbo entry path. Actual native visit entry can create one seven-original incarnation, deriving its orbit from canonical planet/sun, actual scene structures, all seven catalogue meshes and native admission proxies, and the weakest actual speed/acceleration/turn bounds. Existing originals retain their saved anchor and phase.

Before ordinary departure clears the ledger, park exact originals within the same private travel candidate. Offsite and unbound originals accrue no orbit, hull, shield, fuel, heat, cooldown or electrical recharge progress. Rebase enabled ordinary electrical clocks with zero elapsed recharge at actual native admission boundaries; disabled EMP ownership and deadlines remain with the actual EMP owner. Revisit imports the same surviving logical keys once. Only numerical world/camera position-orientation roundoff may differ during checked import; every resource, resource clock, velocity, cargo and aggression field remains exact.

## Acceptance and validation boundary

Define meaningful source regressions for actual launch/dock/relaunch, departure/return, whole original identity retention, decoded populated/threat registry refusal with the gate disabled, exact original unbound freeze versus an unowned same-catalogue NPC, charge-preserving rebasing, disabled-EMP refusal, actual rotated-camera import, electrical-clock mismatch refusal and actual after-destination galactic-arrival rollback preserving original drive, fuel, galaxy/system, cargo custody, registry and bodies. Failed candidates cannot publish partial rebasing or admission.
