The existing guidance validator still calls `HullSweepSafety.validate` exactly once and returns that same result's original clearance. A `DEBUG`-only observer runs when `ELITE_NATIVE_WORK_TRACE=1`. Release builds contain neither the observer nor its flag lookup. Default debug execution emits nothing. No test, movement, geometry, margin, clearance, budget or authority predicate changes.

## Recorded context

A direct standard-error JSON line prefixed `ELITE_NATIVE_WORK_SWEEP_RESULT` records the actual failure (or explicit null), obstacle identity (or explicit null), minimum sampled clearance (or explicit null), distance-query/triangle-test/node-visit counts, sweep purpose, physical time, required clearance, player radius and duration. It also records the existing primary identity and catalogue ID, ship start/end pose, initial velocity, acceleration, angular velocity, target start/end pose and linear/angular velocities, surface position and work position. The explicit-null wrapper distinguishes an absent identity or failure from an accidentally omitted field. Nothing is recomputed from a different snapshot or another geometry evaluation.

Successful requested-work sweeps emit no record. A refused work sweep emits its result and sets one closure-local diagnostic Boolean for this guidance step. Its ensuing braking result is then emitted even if braking succeeds. After that result, `ELITE_NATIVE_WORK_SWEEP_FAILURE_COMPLETE` reports the same physical time and whether the requested failure and braking result were captured. A failing braking proof reached without a prior work failure also emits its result and a completion marker with `workFailureCaptured=false`. The Boolean is neither Game state nor a cache or global hook; it resets on every guidance step and never controls clearance or motion. In the original hold controller, one requested refusal therefore produces at most two result lines and one completion line per step. An encoding error instead emits `ELITE_NATIVE_WORK_SWEEP_TRACE_ERROR`; missing context is not claimed as evidence.
