# Live original worlds and station stock

The development implementation installs all 2,048 ordinary original worlds in eight galaxies through the single authenticated OriginalWorldCatalogue. Every native StarSystem retains its complete original record, including all 29 authored fields. Charts, native travel, route search, conditions and mission endpoint checks use direct Cartesian Double light-year coordinates, including negative values. Distances use Euclidean hypot without the BBC coordinate conversion or floor. Galaxy bounds and names come from the same source. Native procedural appearance and encounter seeds derive deterministically from the original authoring seed plus exact world key; seed bytes do not generate a second set of world names or coordinates.

OriginalMarketCatalogue authenticates the 34,816 original initial quotes once. Commodity names, units and base manifest values come from original authoring. Each station has distinct ask and bid prices. Buying pays the ask and removes actual stock; selling receives the bid and adds stock. AUTO exports, carried-cargo estimates and route trade scores respect those quote sides. Changed stock lives in Commander.originalMarkets, keyed by exact galaxy/system identity. Leaving, arriving, loading or reopening a market does not refill it. Pristine worlds share cached immutable seed arrays; current changed stock is bounded and retained by the current commander save. Invalid versions, foreign identities, quote forgery, bad quantities and wrong row counts are rejected. No predecessor save converter or world alias is introduced.

PLUGH remains a separate hidden system 256 in each galaxy, outside the 2,048 ordinary records. Its existing anchor-and-offset policy now uses explicit Cartesian light-year offsets near the current original anchor. It inherits the anchor market's original quotes with the existing discount, finite initial stock and existing discovery/fitting rules. No original-world record is fabricated for PLUGH, and XYZZY grants no clue, secret-world discovery or tutorial authority.

Navigation and trade practice now binds the actual original training world and selected original destination, and re-authenticates complete endpoint records on ordinary cold load. Uppercase original keys are accepted only through exact catalogue equality; arbitrary key syntax or saved bindings grant no authority. Actual dock receipts, fitting, route fuel debit, paid fuel, identified cargo, sale, return and reception remain required. A real loss qualifies and no reward or profit is invented.

This change does not activate the 171 staged ship definitions or replace the starting ship or equipment catalogue. It does not yet implement later economic-epoch price updates or stock recovery from the retained economic authoring configuration. Those policies remain explicit full-goal work. Existing ordered mystery and clue gates remain in force. Author checks are strict Swift formatting, Markdown lint and whitespace checks only; the coherent compiler, focused native/current-format tests and maintained coverage, sanitizer and leak gates remain required. No runtime, visual, full gameplay or release acceptance is claimed by this source note.
