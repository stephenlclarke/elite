# One authoritative fitted-energy EMP profile

The current EMP runtime uses a fixed range and instant disablement. The newer requests require energy-grade-dependent strength and reach, a ten-second charge and a target-centred attenuated area pulse. Runtime, electrical reserves, source custody, player disablement, ECM cancellation and crew recovery are separate integration work; defining constants does not deliver those features.

Provide one immutable checked-Sendable profile resolved from the validated, actually fitted energy component and its canonical grade. Stock, intermediate, advanced and Elite grades represent progression stages 0, 1, 2 and 3. Stored devices, legacy labels, recharge ratios and the number of upgrade receipts must not independently grant stages. Migration and earned promotion remain explicit existing transactions. Invalid equipment must refuse resolution rather than receive a free stronger profile.
