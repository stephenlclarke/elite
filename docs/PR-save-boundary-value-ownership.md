# Own native save snapshots off the publisher stack and borrow validation storage

The native save barrier returns an internal immutable checked-Sendable owner containing the same live Game and disk Commander previously returned as a tuple. Construction explicitly performs the original return copy of the inout Game and consumes the existing persisted Commander; it adds no snapshot, mutation or validation authority. Publisher preparation returns this owner before entering writing. Failure observation and the original whole-candidate assignment/Alien receipt/new-save receipt sequence run in separate non-inlined phases after writing returns or throws. File-access, migrations, calendar, actor persistence, native-save guards and all error/commit order remain unchanged in one synchronous actor turn.

Commander script-state access now yields existing optional storage directly through `_read`, or an uninstalled empty default when absent. Setter and `_modify` behavior, stored fields and CodingKeys remain unchanged. Result-queue validation explicitly borrows the candidate's Commander into its original full validity getter; failure-message access and later queue capacity/emission storage are separate. Campaign validation retains the original parent iteration and shared child-ID set, but completes full scope, child-binding and parent-binding checks in order in distinct frames. Every predicate, equality, binding authority and fallback remains the same; owned scope parameters remain available for closure capture.

Correspondence rejoins publisher preparation/write/failure/commit operations, result-queue guards/emission and every campaign predicate in their original order. It recovers complete original files after reversing only the ownership carrier/return and same-value read plumbing. Native preparation guards and mutation bodies, ordinary-writer call sites, save format/encoders, physical state, transaction rollback and the integration's diagnostic value-parameter correction are unchanged. The owner never escapes the per-publication operation as mutable state and is never encoded or cached.

Author checks are strict Swift formatting, scoped Markdown lint, whitespace and source correspondence; there is no author compile/test/native/debugger/disassembly/profiling run. G1 performs one independent source review and one batched build after safe closure of its current observation, then reruns the two actual focused failures. Known passing groups are retained. Source establishes changed ownership/lifetimes, not emitted frame sizes, sufficient encoder stack margin or runtime acceptance. If a fault remains, the minimal next observation is next-build buffer/copy retention at publisher-to-write and Commander-to-campaign validation, tied to the matched fault, before widening into encoder implementation.
