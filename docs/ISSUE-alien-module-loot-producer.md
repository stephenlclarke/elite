# Produce distinct alien attachments from actual Thargoid salvage rolls

The alien attachment model defines four stackable module types and permanent upgrade sources, but the current Thargoid loot profile only rolls legacy artefacts. Those model definitions alone do not make modules reachable. Add the eight matching physical/upgrade definitions to the actual producer, preserving artefact outcomes, human pools and retained plans.

New items must exactly match the attachment ledger's typed source contract and remain separate from ordinary capped scalar fitting. The central owner must integrate the new-ID validator before the salvage ledger's generic scalar branch and perform real collection, PLUGH fitting and durable source consumption. See [implementation](PR-alien-module-loot-producer.md).
