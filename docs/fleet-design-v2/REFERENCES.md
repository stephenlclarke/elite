# Shared-chat design reference review

Reference supplied by Stephen: [ChatGPT shared review](https://chatgpt.com/share/6ae4555e-326c-83ed-8736-f0d1f16d4a60?ogimg=plain), retrieved 30 October 2026. The public page's embedded conversation data and four ship/industrial reference images were inspected. The normal web fetch failed; the public HTML was retrieved directly. Browser control was unavailable, so no browser view or interaction is claimed.

The conversation distinguishes illustrative search images from actual game assets. In particular, one ship reference is a Star Citizen Sabre Peregrine brochure; other examples lead to an EVE-related guide, an artist concept page and stock imagery. They are not new original L337 hull designs and have not been copied into this pack or into game resources. The name Peregrine in that brochure does not make that external ship an approved design for L337's Peregrine family.

## Useful principles carried into this design

| Observed reference | Useful design lesson | Application |
| --- | --- | --- |
| Modular industrial mining craft | Large readable machinery/cargo assemblies, service joints, receiving apertures and concentrated work detail | Distinct container Bison, rack Carabao and protected-hold Warthog; visibly equipped miners and the Tithe machine family |
| Large industrial structure with exposed service volumes | Function is readable from repeated modules, working interfaces and protected power components | Tithe Utility/Transport service buses and meaningful station/platform openings |
| Detailed fighter technical sheet | A convincing integrated cockpit, a clear engine/weapon arrangement and clean major surfaces can coexist with fine recessed details | General human attachment, panel/vent and silhouette criteria; no traced outline, texture, markings or component layout |
| Shared chat's progression review | Starter, optional specialisation and advanced work are more useful than one mandatory ship ladder | Preserve the Peregrine start; make miners, hunters, liners and haulers useful alternative choices; gate Medusa separately |

These are design principles. No claim is made that an external illustration is owned, licence-free or suitable for redistribution. The final meshes and textures must use the existing original L337 inputs and newly authored construction. The shared chat's suggestions for another app title, mission order or game mechanics remain suggestions and do not supersede Stephen's accepted requirements.
