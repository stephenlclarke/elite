# Finish declaration validation before constructing an actor template

`missionActorAdmissionTemplate` becomes a non-inlined wrapper over two private non-inlined phases. Declaration validation retains the exact NPC hull/state checks, first matching declaration and full `definition == npc.fit.definition` operator, or the exact classic hull/NPC mismatch guard. It returns a private immutable fit containing only the original selected NPC state/definition or hull. Construction immediately consumes those selected values in the same synchronous invocation; there is no caller-supplied authority, cache, suspension or new Game/Commander copy.

The construction phase retains the original branch bodies for energy, parts, exact installed geometry and legacy component identities, followed by the identical condition/resource/velocity/cooldown, finite mesh/bounds and canonical-body code. Source correspondence rejoins the two unchanged declaration guards with those construction bodies to recover the entire old template body byte-for-byte. Replacing the new private phases with that original method recovers the full original source file. The surrounding sorted actor loop, prepared-condition checks, retention/source validation and native admission are unchanged, so validation never moves across actors and error text/order remains intact.

Author validation is source correspondence, strict Swift formatting, scoped Markdown lint and whitespace checks only. No compiler, native, test, CI, debugger, GUI, renderer or probing job runs. G1 independently reviews and integrates the frozen source, compiles once, inspects the actual phase boundary and first runs only the unchanged two-argument anchor regression. Admission refusal coverage follows its result; the passing original timers need no repeat without a changed-path reason. No runtime pass, compiled-frame reduction, aggregate peak or full-CI acceptance is claimed.
