# feat(diagnostics): observe native planet frame pacing

The optional `--profile-planet-frames /absolute/new/output/directory SOURCE_SHA` mode creates a temporary normal commander at a deterministic high-technology industrial world and launches through the ordinary native game path. Its AppDelegate uses the existing frame/deadline, ordered commands, controls, actor advance, view and renderer. A main-actor observer feeds the actual two-contact yoke and number-key view controls, records submitted frame identities and real draw callbacks, and transitions through native AppKit fullscreen acknowledgement. There is no separate manually paced drawing loop. Normal launches keep a nil observer and their existing runtime/session defaults. See [the measurement gap](ISSUE-native-planet-frame-profile.md).

Each window has sixty warm-up frames and two hundred forty measured submissions, followed by an excluded capture/transition phase. The output includes exact executable hash, declared source identity, scenario/system/controls, observed backend, drawn planet count, viewport pixels, actual fullscreen flags, stage wall spans, frame-interval percentiles and raw samples. Rounded missed sixty-Hz intervals are estimates from observed draws, not physical scanout or input latency. Actor spans include queue time and drawing spans include GPU waits; they are not CPU-only timing. Output success means a complete controlled measurement, not a smoothness or release gate. The result is candidate-only unless an independently identified baseline uses the exact same instrumentation and scenario.

The diagnostic uses a CommanderSaveSession with no UserDefaults and a temporary output save URL, disables startup restoration and default external script loading, and never chooses a new commander destination. Real AppKit view caching generates its PNG captures. The ordinary deadline/sleep and runtime ordering remain. Source formatting and whitespace checks pass; compilation, isolated native execution, protected-input checks, before/after comparison and final CI remain pending. No performance result is claimed by the source alone.
