# Reject nonfinite effective runtime statistics at Commander admission

CR-07 identifies canonical saves whose individually finite component statistics overflow when multiplied by hull capacities or recharge rates. A known energy component with capacity multiplier `1e308` can otherwise load infinite game energy. Navigation fuel multipliers can also exceed the representable Int cost even while all operands are finite.

Check actual fitted runtime products before derived admission checks or runtime publication. Preserve stronger finite grandfathered components and held property; do not introduce current grade or terminal clamps. Refuse a fit that would activate unsafe statistics atomically. See the [repair handoff](PR-effective-equipment-statistics.md).
