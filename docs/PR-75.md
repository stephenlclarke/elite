# Issue 75: scope ship media keys to the actual portrait renderer

`shared_hash` now uses a maintained renderer file list instead of the all-EliteCore wildcard. The call path is `exportShipMedia` in ShipMedia.swift, `Display.shipPortrait`, `CatalogueShip.previewMesh` and `Display.draw`, then `imageFor` and `drawFrame` in NativeGraphics.swift. The portrait supplies its own normalized catalogue mesh, explicitly sets front view and shaded panels, and has no native mission actor, rock, station or beam state. It uses the Quartz CPU path without a ShipPanelRenderer, so GPU shaders and unrelated simulation/custody/service files are outside this dependency set.

| Input | Retained dependency |
| --- | --- |
| Catalogue decoding and load validation | ShipCatalogue.swift, ShipCatalogueMetadata.swift, ShipPerformance.swift and each individual ship TOML |
| Mesh, basis, orientation and normalization | Geometry.swift, AutoTargetControl.swift and ShowroomGeometry.swift |
| Materials and authenticated texture binding | ShipAppearance.swift, ShipTextureAssets.swift and OriginalShipTextureAssets.swift |
| Projection, lighting, raster sampling and frame commands | ShipRendering.swift, ShipTextureRaster.swift, Graphics.swift and Display.swift |
| Portrait settings and text | ShipPortrait.swift, CockpitDisplay.swift and Display.swift's palette/font |
| Native image and GIF output | NativeGraphics.swift and ShipMedia.swift |
| Packaging and TOML decoder resolution | Package.swift and Package.resolved |
| Texture bytes and manifests | Complete ShipTextures and OriginalShipTextures trees, with relative names and content |
| Shared Game view transform | The exact uniquely bounded viewPosition declaration; missing, renamed, duplicate or reversed boundaries refuse hashing |
| Empty scripted-beam guard reached by Display.draw | ScriptNPCRendering.swift |

The fixed portrait reads only the view transform from Game.swift. Hashing that uniquely bounded source declaration keeps changes to the actual transform visible without invalidating media for an unrelated Game method. The maintained list must be updated when this call path gains a dependency. Required file removal fails closed. Both texture trees include add/edit/rename/delete detection; the earlier code covered only ShipTextures.
