# Separate live NPC beam query and effect lifetimes

The NPC beam entry now retains only private synchronous reference facts across cold phase calls. Its first operation remains the real `ensurePhysicalActors`; it reserves no local full body, collision contact, flight snapshot or impact receipt. The original source query and native preflight finish before emission allocation. Two private non-Sendable classes own the same contact and flight snapshot values through the remaining phases, without copying Game or introducing a new transaction/publication boundary. They form a local acyclic reference chain and cannot escape the synchronous call.

| Phase | Preserved behavior |
| --- | --- |
| Actor rebuilding and preparation | Rebuild physical actors first on the live Game, even when a later guard refuses. Select the same first positive-energy body, reject EMP-disabled/missing-owner/zero-position sources, compute the same launch point, and perform the same nearest occluding ray with source exclusion and player inclusion. Run the same native preflight before any origin allocation. Preparation refusal retains the original earlier live effects. |
| Emission | Copy only `commander.flightSimulation` at the original point after preflight, then call the same `makeAttackOrigin` for the captured actual emitter. A refusal adds no new rollback. Store the same flight/origin values in private facts before the impact frame opens. |
| Native impact | Repeat the same contact script-target branch and call `applyNativeMissionContact` with identical contact, owner origin, damage, nil laser/mount and launch position. On refusal restore only the saved flight simulation and return before heat or emission finish. On success immediately project the same receipt. |
| Ordinary impact or miss | Apply the same native combat hit and energy multiplier, still ignoring its optional result as before. A missing contact records the same discharge with nil target and launch as both positions. No new authority, guard or refusal is added. |
| Completion | After impact temporaries unwind, search the same body ID and record the unchanged heat formula if it remains. Finish the same emission last. Cadence, damage, ammunition, law, source joins, occlusion and encounter ownership stay with their existing code. |

`@inline(never)` keeps preparation, emission, impact and completion boundaries explicit. The preparation owns the contact containing its selected-body value; the emission owns that preparation, the original flight snapshot and origin. There is no whole-Game copy/candidate, new public API, asynchronous operation, Sendable bypass, global state/layout change, actor escape or changed test/stack/concurrency budget. AppKit remains outside this path. Source structure is not proof of compiled stack margin or runtime success.

Author checks are a concise diff/security correspondence, strict Swift formatting, paired-note Markdown lint, whitespace and source-scope checks. No author compiler, native app, test, profiler, debugger or ABI job is run. One independent review precedes a coherent build batched with the other reviewed CI repairs. Focused execution must include the unchanged actual failed full-stock Cobra method and directly affected beam occlusion, EMP-disabled emitter and native contact/refusal/law paths; retain unrelated earlier passes. Current-format correctness remains required under the user's backward-compatibility waiver. Full CI, coverage, sanitizer/leak and release gates remain incomplete.
