# Preserve original section cycles and seal native exports

## Motivation

The paged alien store needs actual original section evidence. A ledger revision is insufficient to seal it because live lot and wreck poses can change without advancing that revision. The original cutter also consumes a fresh work budget after every release batch of up to eight lots; its issued cursor cannot stand in for completed current work.

## Required behavior

Use one section calculation for the existing producer and the forthcoming native hot session. Preserve original seed, structural material, ordered chunks, mining damage, release geometry, pool refusal order and per-batch work reset. Export only inspected, fully checked original plans and current custody, retaining whole settlement proposals and genuinely missing historical fields. A transfer must reject any intervening semantic ledger change or replay and retain original audit and ordinary stored technology.

## Scope and remaining work

This source seam does not enable native paged cutting, collector admission, legacy world records, PLUGH fitting or new equipment effects. The actor must join and durably publish all transferred custody, normalized history and new property in one candidate before any gameplay call to the transfer API is added.
