# refactor(runtime): separate frame preparation and completion lifetimes

`GameRuntime.advance` now prepares its original flags, preflight and clocks in a private synchronous actor helper, runs the unchanged physical tick and pending station entry, then completes the original restoration/events/timers/world jobs in a private synchronous helper. Only the original Bool/Int context crosses these boundaries. A preflight refusal still returns the current paused snapshot; a restoration refusal still retains physical effects and returns without later event work. All original call order and short-circuit semantics remain. There is no await, state boxing, stack-size flag, serialization, skip or guard relaxation. See [the measured pressure](ISSUE-runtime-advance-lifetimes.md).
