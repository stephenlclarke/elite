The cache contains only the unchanged local mesh and immutable PreparedHull, including original primitives, conditioned/support flags and BVH. No world pose, query result, source admission, offer, namespace reservation, custody/binding or receipt is stored. Every original authoritative factory/source/context/protection/budget/player/other-actor/celestial check and actual pose-specific mesh query remains in the original order.
