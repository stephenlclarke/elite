# Defend a reported clean commander inside the station protection zone

The remaining hostile freight failure occurs in legacy galaxy 0 / system 27, which has government 0 by the current Universe seed calculation. This is a source-derived identity fact, not a new runtime diagnosis. Actual native unlawful-hit resolutions are observed within station range and forwarded by `applyCrimeResolution` into `StationSecurity.receive`, irrespective of whether the owner is the player or an NPC. However, `advanceInvestigation` rejects every ordinary report in government 0, while `advanceCalm` correctly creates no routine anarchy patrol. Consequently even a real assault against the current clean player inside the 1,200-unit station protection zone cannot dispatch station police; only attacks on the station itself bypass that government gate.

The user requires real station defence of clean commanders, not blanket safety or guaranteed victory. A currently joined, witnessed local assault should request actual police through existing exit/admission/weapon rules, while unreported, remote, wanted, foreign/stale, dead or obsolete threats do not create guards. Preserve ordinary government-dependent investigations, no routine anarchy patrols, source law and strict physical docking. See the [repair note](PR-station-local-clean-commander-defence.md).
