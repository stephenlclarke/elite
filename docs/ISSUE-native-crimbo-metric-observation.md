# Project-local metric projection of attained Crimbo motion

## Problem and ratified decision

The native observation records actual world-unit movement, but mission thresholds are expressed in metres. Mission Researcher's unit audit and Root's decision ratify a new project-local metric revision, `native-flight-metres-v1`: one native local world unit equals one game metre, with physical seconds unchanged. This is a project convention, not a recovered historical, SI or astronomical scale. No geometry, physics, ship catalogue multiplier or saved progress remapping is authorized.

## Required behaviour

Project only the current retained original Santa observation. Authenticate the provider, original member and ordinary NPC binding, manifest, world, player, visit, runtime epoch, physical frame/time, actual endpoints and velocities. Pin the metric revision and reject missing/mismatched revisions, stale facts, cross-epoch/scene baselines and duplicate/replayed end frames or times. Distance must be actual signed tangential displacement; requested phase, radius and delta cannot earn progress.

Range and relative speed need bounds over the actual native trajectory. Ordinary native movement rotates the camera once and translates once, including normal turning and autopilot controls. Accepted work movement has an existing quadratic trajectory record. Endpoints alone cannot establish the interior of an unknown path. Reject absent, refused, collision-modified or mismatched trajectory authority.
