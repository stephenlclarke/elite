# Startup ship panel drawing cost

The original approved SH123 startup ship still spends about 67 ms at the 95th percentile in native drawing after the qualified clipping optimization. Its full projected triangle stream is currently drawn with one Quartz fill/stroke path per panel. The geometry and materials must remain intact; reducing the mesh is outside this change.

Deliver a bounded title/credits-only Metal panel path using the installed Metal/AppKit frameworks, with the original Quartz renderer available for unready, unavailable, unsupported or failed acceleration. Other scenes, exported media and wireframe modes retain their existing behavior. This is a rendering delivery within the existing milestone, not a new feature or a frame-rate claim.
