# Admit and simulate actual missiles before applying impact damage

Player and source-native NPC missile launches now prepare an atomic candidate game state, admit one typed projectile, capture its actual launcher and target identities, and record launch evidence before publishing the launch and charging finite ammunition. A refused launch preserves the original game. Actual missile updates use the existing finite ordnance simulation and attributed combat pipeline, including nearest-mesh occlusion and catalogue geometry. Original energy-only ships retain the native one-missile kill rule; shielded NPCs use the standard missile's finite damage.

ECM retains a stable activation identity and applies the actual profile response. Plasma remains immune; the seeker resists one unique activation. Destruction speech and retaliation count only actual terminations by the player's active field. Original target ECM probability follows impact resolution. Old untyped scene fixtures retain the native compatibility path, while both actual player and native NPC missile producers now emit typed bodies. Thargoid drone creation and mission encounter spawning remain separate work.

Twelve runtime regression methods cover actual player/NPC launch, finite impact and shielding, physical occlusion/interception, legacy Constrictor behaviour, refusal without mutation, ECM profile response, and three actual-launcher replacement timings. Independent source review found and prompted a fix for return fire using a reusable display ID. Identification, confirmation and execution now retain and verify the actual launcher identity; untyped historical fixtures keep an explicit compatibility fallback. The immutable witness coordinate is consistently the launcher's centre at emission, with the projectile initially offset to its muzzle.

Focused validation passed on clean `98451bf4643838edef8b46e8cd211943e6056a39`: 35 methods across the new runtime and pure ordnance suites plus existing retaliation, ECM, Naval, Constrictor and combat fixtures; test time 8.493 seconds and command time 15.1329 seconds. The initial compile failure from mutating calls inside Swift Testing assertions and subsequent three incorrect fixture expectations remain in raw evidence. Launch incurs assault before impact, an explicit 100-point shield fixture checks overflow damage, and the damage/bounty fixture launches outside the target's immediate beam-interception range. A separate real-tick regression verifies that close-range return fire can intercept a missile. No production semantics were changed to satisfy these fixtures. Strict Swift formatting and whitespace checks pass; the production commander save is unchanged.
