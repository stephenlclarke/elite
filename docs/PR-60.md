# Reduce immutable fixture construction stack pressure

Refs [issue 60](https://github.com/stephenlclarke/elite/issues/60). Continuation, cassette service, vault key, ark producer, ark receiving, crew producer, crew pickup and rescue finance fixture containers now use final class storage. Their stored properties are immutable and callers do not rely on independent mutable copies. Constructor bodies and all assertions remain unchanged.

This reduces nested value-frame pressure on the path identified by the matched 60c9 stack-guard report. It does not change production code, actor isolation, runtime stack limits or the 305-method qualification selection. Affected declarations are typechecked; actual hosted execution and independent verification remain required. Earlier unmatched SIGNAL4 runs are not attributed by this correction.
