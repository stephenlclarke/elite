# Frozen original authoring sources

These files preserve the original authored campaign/finale stories, schema and engine contracts as provenance. They are not an alternative current gameplay definition set. The [canonical JSON](../definitions/) and [controlling resolution](../gameplay/GAMEPLAY-SPECIFICATION.md) include later physical recorder custody, clock rules, guaranteed clue continuity, distinct operation profiles and revised activity ordering. Where an original TOML differs, those explicit later rules control implementation. Source paths in the original authoring text identify provenance, not a required external installation.

The [consolidated source manifest](../../references/CONSOLIDATED-SOURCES.json) records each source and hash. The [implementation guide](../../implementation/README.md) defines how to combine these inputs without importing retired stories or creating a second work queue.
