# Apply missing mission checks to raw commander loads

Raw JSON loads now call the same unavailable-content suspension check as versioned saves after native equipment and calendar migration and before final commander validation and publication. This changes only the unavailable mission status; the pack's historical property and original files remain retained.

The existing complete historical gear regression requires original ownership, loan rights, condition, modifications, receipts, absent consumed gifts and unchanged source bytes, then checks the missing mission is suspended. Source formatting passes; targeted execution and complete CI remain pending. Motivation: [issue](ISSUE-raw-save-missing-missions.md).
