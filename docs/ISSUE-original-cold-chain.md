# Original cold-chain clinic service

## Motivation

W01 has native finite stock, protected sample custody, flight integrity, objective/reception, payment and first-success support, but no installed production service or station-board consumer. SDK support alone does not make the approved clinic service playable.

## Approved scope

An ordinary H0 service carries one sealed sample from Cedamar G01-S085 to Celalen G01-S241. At Celalen the player separately confirms arrival and receiving handoff at the same actual orbital dock. Six original samples form one finite batch, with no replenishment. Payment is 405 CR: 320 base plus 85 for the single route leg. The explicit authored integrity allowance is 2700 armed-flight seconds after pickup, not a measured journey bound. No berths or accreditation are required for this ordinary variant.

## Acceptance

Use the existing station board and arrows, Confirm and Esc. Show the actual route, capacity, reward, hazard, allowance and remaining budget. Back changes nothing. Stable source/unit identity survives reopen and reload, while fresh live quotes retain native epoch/dock rejection. Existing native operations control stock, capacity, custody, timing, loss, objective, actual receiver and atomic payment/clue publication. Exact production content grants only its own permanent first-success clue after reception. Default discovery preserves existing providers and installed content ordering.

## Boundaries

No Game, Director, native command, persistence, economy, person, timer or receipt framework changes. Artwork display, the other five services, advanced accreditation and broader playable/release gates remain separate work. No remote issue or PR exists.
