## Motivation and observed failures

Five methods covering seven cases failed in the preserved full review run 352. Provider-free book reading retained its library cursor but compared the loaded Commander against a snapshot taken before first publication. Three precious-cargo cases made the same comparison. Current publication explicitly persists the existing economy mining ledger and initializes a missing calendar for current equipment. The book already has its calendar from genuine mission acceptance.

The cabin fixture bought four five-tonne cabins and assumed they filled a thirty-tonne hold. Its unlimited-cargo setting does not expand the finite physical accommodation capacity. The zero-fuel military fixture encoded actual current V3 equipment as raw legacy JSON; both that load and its later Commander-only legacy load reject current state before the intended reach assertions. Military zero fuel cost remains valid grandfathered equipment. The chart expected the old fifteen-second scalar countdown despite the actual fitted Basic drive's ten-second policy.

## Required outcome

Keep actual purchases, custody, identities, retained book content, reading cursor, paid receipts, maximum supported quantities, refusal rollback, fuel debit, arrival and canonical courier generation checks. Derive expected publication state before saving, verify genuine current chunks and reload without writing. Fill the cabin hold with actual remaining freight while keeping unlimited cargo and all four paid cabins. Use current save transport for current military equipment and assert literal Basic timing with actual fitted provenance.
