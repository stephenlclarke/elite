# feat(flight): project attained Crimbo motion into the local mission metric

## Result and implementation

A new opaque, non-Codable `NativeCrimboMetricProjection` applies ratified `native-flight-metres-v1` consistently to signed attained tangential displacement, conservative range and relative speed. One native local world unit equals one game metre; actual physical seconds are unchanged. The original 5000 m / 100 m/s / 5 s contact, 6000/12000/18000 m checkpoints and 8000 m / 60 s escort terms remain unchanged. No catalogue 18 multiplier is applied again, and existing saved metre values are not reinterpreted.

The owned runtime sample/fact gains optional transient provenance for the original manifest, world, player, orbit scene and ordinary logical NPC identity. Projection requires equality with the current retained fact and authenticates that provenance against the current original Santa registry/ledger/body join, epoch, visit, frame/time, endpoints, velocities, non-EMP ordinary ownership and no current entry/contact/fatal/paused/docked state. Signed tangent displacement is checked again against actual subject displacement and the original orbit anchor. Missing or mismatched metric revisions reject. An immutable projection can be read repeatedly; revalidation against the consumer's current baseline rejects duplicate/replayed frames or times and cross-epoch/scene input. No progress mutation or mission folding is introduced.

Ordinary controls use the existing native rotate-once/translate-once positional model, captured at sampling and checked against the exact retained endpoint and actual ending velocity. Nonzero pitch, yaw and roll remain supported. Accepted work motion uses the genuine `lastAppliedWorkMotion` adopted by `moveWorkFrame`, with checked start, duration, quadratic position, retained end and actual ending velocity. Missing or mismatched provenance rejects even if endpoints exist. Santa's ordinary native translation must match its sampled constant world velocity. For relative quadratic motion, the maximum endpoint range plus `|acceleration| * dt^2 / 8` bounds the entire chord deviation; the maximum endpoint relative speed bounds the affine velocity, also including the sampled pre-turn boundary velocity for ordinary controls. Small conservative roundoff allowances are included.

## Missing joins and compatibility

Projection exposes explicit missing sensor contact, communications, living crew, tracking-throughout and saved metric revision authority. `missionInterval` is always nil. Scanner rendering, selected target, visibility and an alive body do not mint these facts. G1 must supply genuine native owners and persist an authenticated metric revision before any production fold can be integrated. Existing provider readiness, route availability and interval emission are unchanged, and the production lifecycle gate remains false by default. No shared Game, provider, mission-observation or save file changes are included.

Transient provenance defaults to nil, preserving existing sample/fact call sites and allowing raw world-unit observations to remain useful without metric authority. No save format, geometry, physics or persisted progress migration is introduced. The local revision string supplied to this numeric factory is a compatibility check, not evidence that the current save contains a revision.

## Authored validation and acceptance boundary

Eight test methods define 32 cases, using actual `GameRuntime.advance` and direct `Game.tick` paths. They cover five ordinary steering modes, physical delta clamping, genuine adopted quadratic work movement with 101 interior range/speed probes, actual-tick endpoints with deliberately removed work authority, 17 current identity/fact/state refusal probes, five replay/baseline refusals, missing/different metric revisions, unchanged saved metre values and unavailable mission/provider readiness, and actual no-tick invalidation of the retained projection. Boundary tampering is labelled and cannot establish native authority. Throwing, mutating and awaited operations are bound outside assertion macros, except intentional optional-value requirements.

Local validation is limited to Swift formatter/parser, strict scoped lint, Markdownlint and source/diff/hash checks. Compilation, typechecking, test discovery/execution, native/GUI jobs, performance and applicable `make ci` gates remain exclusively G1-owned; no runtime acceptance is claimed.
