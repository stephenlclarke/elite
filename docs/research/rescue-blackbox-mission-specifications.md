# Rescue Stations: black-box recovery and conspiracy variant

P30 scenarios3 and3a are ready as `PROJECT-P30-BLACKBOX-3-v1` and `PROJECT-P30-BLACKBOX-3A-v1`. Travel to another system's asteroid field, scoop one unique black box and return it to the accepting orbital RRS station within a route-based deadline. Variant3a removes the field ambush and adds assassins on the return journey. Apply [scope v4](implementation-scope.md), the [RRS board/HQ extension](rrs-contract-board-specifications.md), [cargo/crew capacity](crew-and-passenger-specifications.md) and [shipyard custody](player-shipyard-design.md). No surface stage, walking, passenger transport or Frontier mission is introduced.

## Offer, route and deadline

Base3 returns false when U>0.6, so source eligibility includes the equality U=0.6. It also needs reputation>=0, bounty<=50 and a qualifying noncurrent, non-nova destination. Straight source distance must be strict>7 and<15 light years, and source routeToSystem must exist with total route.distance<=25. Destination selection is uniform over that established set. Source scoop/cargo admission checks are commented out; the selected project requires a working scoop and reserves one free tonne at acceptance so actual recovery cannot soft-lock. No cabin/passenger requirement is added. Advanced Navigational Array is recommended, not a source offer gate.

Use the pinned O08 integer-y distance `0.4*floor(sqrt(dx*dx+truncTowardZero(dy/2)^2))`. routeToSystem defaults to minimum jumps, with per-edge cost1792+distance, strict improvement and ascending neighbour IDs. Route.time is the sum of each jump distance squared in hours. The source's ordered frontier can choose a different equal-cost path/time from a generic shortest-path implementation. Preserve the saved selected path and its actual route.time, including floating arithmetic and tie ordering; do not choose a different path and silently change the quoted deadline. The independent binding table records both the source result and311 alternate-time ties. Apply live concealment/nova/property changes before offering; source excludes a nova destination and hidden nodes, without treating the default static table as proof of every modified runtime world.

Native source graph edges require the same metric for navigation, jump admission, fuel and travel-time. The current project's floating-half-y formula is not interchangeable. Implementation must support the selected O08 adapter for these actual player jumps; a black-box courier has no escort leader whose wormhole can hide an incompatible route. Missing navigation support is an implementation gate, not permission to replace the source route with an easier objective or claim fidelity. Actual current drive/fuel/refuelling capability must support the chosen itinerary; store the adapter/version rather than switching distance rules midattempt.

Quote base reward=floor(route.distance*30) credits. Deadline duration is `(2.3+U)*route.time*3600` simulation seconds, using an independent saved U in[0,1). Source starts the deadline during preview; project starts that unchanged saved duration on actual Accept Confirm as the explicit preview-aging repair used by the other completed RRS jobs. Preserve the source one-way minimum-jump time basis and2.3..3.3 multiplier, rather than substituting a fastest-route or arbitrary two-hour timer. Example source route G0/system1->242->5 has total9.200000000000001LY,52.000000000000014hours and276base credits. Faster travel via a different valid path remains possible; it does not reprice the accepted contract.

Source missionAvailableCount recursively returns1 plus another count with20% continuation. The actual shared board re-evaluates that getter at every for-loop condition, not once per family. Consequently the probability of reaching slot k is0.2^(k*(k-1)/2), before variant replacement: slot2 is0.2, slot3 is0.008. Do not silently replace this with a single geometric board-count draw. Selected finite repair uses an iterative geometric getter capped8 for each original guard evaluation, and at most eight resulting family slots; label that rare-tail bound as a project safety choice. Each offer receives a stable saved target/quote identity; selecting/closing another preview cannot reroll or overwrite it.

Accept reserves the unique one-tonne mission item capacity and the exclusive RRS assignment slot, saves the exact station/route/danger draws and starts the deadline atomically. It does not auto-launch, refuel, fit free equipment or pay money. Back/closing does not accept, and explicit decline has no failure penalty. The map preview uses an isolated chart selection with no mutation of the player's real navigation target; the source restoreDestination truthiness loses a previous system0.
