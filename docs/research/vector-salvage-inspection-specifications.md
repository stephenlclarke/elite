At bounty<=7, save station, start clock, wait/warn/compliance/freight counters, pending fine0 and optional other-special-goods list; run every10seconds, source initial delay0. This is an escape boundary, not an invisible arrest. Within the active band, pre-scan elapsed >400seconds aborts as a technical failure, without invented penalty. At exactly400 do not abort. ### Freight scan sequence and custody

After drone activation, each following10second tick processes one source step:

1. At freight0, clear wait/warn and announce document check; set freight1. Ignore the name-checksum waiver in this project as above.

5. Increment freight to5, return scanner and stop timer. Completion receipt is a clean/fined scan outcome, not a cash reward or combat-rank award.
