P30 base scenario4 is ready as `PROJECT-P30-PERSONNEL-4-v1`: travel to a distant GalCop main orbital station, collect one previously rescued RRS pilot and return to the exact station that hired the player. Apply [scope v4](implementation-scope.md), the [RRS board and headquarters adapter](rrs-contract-board-specifications.md), [crew/passenger capacity](crew-and-passenger-specifications.md) and [shipyard custody](player-shipyard-design.md). This is already a space/station mission; no walking, surface landing or ground fight is required. Variants4a/4b remain separate research-open missions and cannot be enabled from this base profile.

## Offer, route and capacity

Base eligibility requires RRS reputation>=10, bounty<=50, U<=0.7 and a nonempty target set. Destination must differ from the starting system, not have a nova sun, have government<=4, have strict straight source distance>7 and<15LY, and have an existing source route with total distance<=25LY. Choose uniformly from the resulting set and save its identity. Live nova/concealment/property changes still apply; the static route table does not prove every modified world is reachable.

Use the completed [source route contract](rescue-blackbox-mission-specifications.md): O08 integer-y distance, source-ordered minimum-jump frontier with edge cost1792+distance, strict improvement/ascending neighbour ordering and actual route.time equal to the sum of each edge distance squared in hours. Save the selected path, distance and actual time; a generic equal-cost solver can select a different time. Actual navigation, jump admission, fuel/refuelling and elapsed travel must support this same adapter. Missing native navigation compatibility disables activation rather than replacing the mission with a shorter route.

Source count is max(1,floor(sqrt(1+9U))), giving1/2/3 per call with probabilities1/3,5/9,1/9. The shared board re-evaluates the count at every loop guard; actual probabilities of reaching slots2/3 are2/3 and2/27. There is no recursive unbounded tail or need for base3's cap. Variant replacement remains separately gated by its own completed profile; it must not appear as an invented extra base4 mission.

Reward is floor((3*route.distance-destinationGovernment)*15) credits. Quote duration3600*route.time*(2.2+U) simulation seconds with an independent saved draw. Source anchors it at preview; the labelled common repair starts the unchanged saved duration at atomic Accept. No special return trip, fuel, cabin, wage, equipment, ship or combat bounty is included in the reward. Advanced Navigational Array is recommended by source synopsis, not a compulsory source installation gate.

The owner requires spare accommodation for passenger missions. Override the source free-flight-hammock/no-cabin promise explicitly: one actually fitted compatible charter berth costs5tonnes of hold and1equipmentunit. Reserve that berth for this unique pilot from acceptance until boarding/return or unused-reservation release. Required operating crew and their intrinsic quarters remain separate; unused crew seats, stored modules and an unfitted cargo expansion do not count as a passenger berth. There is no automatic hammock/cabin grant. An empty5tonne hold without an installed berth still fails admission. Other cargo, equipment and parties must fit simultaneously.

Source generates the name from two randomName calls and a randomInhabitantsDescription(false) descriptor, without physiological statistics. Necessary labelled project estimate: this contracted RRS pilot's generated classic inhabitant description is compatible with the fitted standard common-cabin life-support adapter. Preserve its chosen name, descriptor and canonical species category where established; cosmetic size/colour modifiers do not create new alien races. Known incompatible environmental needs require a real compatible adapter before acceptance; do not fabricate historical oxygen/temperature numbers or convert this living pilot into generic cargo/slaves/operating crew.

## Accepted state and target boarding

Explicit Accept validates the current unchanged offer, exact offering station/HQ, source eligibility, usable route, one free compatible fitted berth, current crew/hold/equipment fit and exclusive active RRS slot. Atomically create attempt/passenger/reservation IDs, snapshot the accepted source parameters and start the clock. Source callback accepting every non-NO/non-MAP value, including NULL, is not adopted. Closing, Back, isolated map preview and decline do not accept, launch, charge, reserve, fail or change navigation. Preserve system0 as a valid real target/marker ID.

The player launches normally and travels to the saved destination's actual main orbital station. There is no mission-specific enemy fleet, field, scoop, slaver base, police chase or kill quota in base4; ambient dangerous-system traffic remains ordinary simulation. Intermediate same-galaxy systems and docking are permitted. No base4 script spawns a new enemy merely because a renderer/population callback runs.

The first valid target main-station docking commits boarding atomically into the berth already reserved by the accepted transport contract; this follows the source automatic docking transition2->100. Record the actual docking timestamp/station receipt and replace the reservation with the same unique aboard passenger. The **Pilot aboard** station-contact screen acknowledges that transfer, changes displayed phase to return home/source101 and marks the exact home route; closing or replaying it does not board another pilot or delete the person. No second cabin deduction or arbitrary crate is added. A wrong station, wrong system, stale callback or absent party/fit cannot set the recovered state. Save/load between docking and acknowledgement retains the committed passenger.

If a legacy/corrupt save cannot fit the reserved berth or prove pilot identity, suspend the contact with a clear capacity/migration problem; do not set recovered anyway or mint an extra berth. A future compatible fit may resume an unfailed transport only through the original receipt. Reaching this main station needs no planet-side operation or playable hangar walk.
