# Per-ship crew and passenger fit list

This list covers the current 170 canonical records. See [crew rules](crew-and-passenger-specifications.md) and [source facts](data/crew-source-evidence.json) for edition distinctions, conflicts and numerical estimation. Expansion hull discovery/deduplication remains open.

Native column abbreviations: C = classic manual documented complement; F2 = Frontier manual operating crew; FFE = recovered operating crew including commander; ED17 = Horizons 2.3 supported flight seats; ED21 = Odyssey Update 8 supported flight seats; D23 = pinned community current-profile flight seats; P30 author passenger25 is rescue interior capacity, not operating crew. These quantities are not interchangeable. Project crew includes the commander; it is a selected adaptation. Initial charter berths default to zero; SH169 Sunray is a verified source-standard exception with one actual fitted berth consuming5tonnes/1equipmentunit, uniquely owned and never repeated on reselection. This is accommodation, not sourced operating crew. Empty-fit ceiling assumes no transferable equipment or cargo and the standard hold, not the current outfitted ship.
