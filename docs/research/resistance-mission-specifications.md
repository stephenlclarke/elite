The operative campaign is squadron command in Galaxy5 (zero-based4), with six generated combat families and morale-based victory/defeat. The separate ENVOY endgame is unfinished in the distributed source and is reference-only, not an invented seventh complete mission. [Twenty-one selected callback checks](data/resistance-source-fixtures.json) establish counts, outcomes, promotion boundaries and source defects under approximate script-object scope; they are not native-engine combat/playthrough evidence.

## Squadron, orders and AI

Four slots can be refitted at command stations to Mamba Armed Racer, Krait Assault Craft, Gecko Bomber or Moray Gunship. Their GW-mamba/krait/gecko/moray dictionaries provide numerical stats; these are loadout variants of canonical hulls, not four newly discovered species or four pilots per role variant. Personnel replenishment resets an inactive slot's name/race/kills/missions/rank/history, with no source cash charge. Unit promotions use strictly>10/30/60/90 kills for ranks2/3/4/5; independent checks can advance multiple ranks in one visit.

On taking an attack, the unit's energy is capped at maxEnergy*(1/3+rank/6), so rank1..4 imply1/2,2/3,5/6,1 and rank5 exceeds its native maximum without creating extra energy. Each Gecko spawn sets a ten-round scripted missile counter and awards a hardened replacement after each shot while the counter remains positive; preserve remaining rounds across dock/jump/reload in the project instead of refreshing stock by despawn. A unit kill increments its pilot's kill count. Unit death marks inactive, increments current casualties and deducts50 mission points. Before a jump, each unit at distance>=20000 is lost/inactive and deducts50; source incorrectly returns on the first nearby unit, so project checks all four independently.

Orders are Regroup, Hold, Engage, Sweep, Check-in and jump-distance check, addressed to a selected unit or all active units. The source responses are staggered one unit per second; Check-in begins after3seconds. Engage uses the player's selected target, sends an intercept order and attempts a missile. Preserve target validity and missile stock; no target means no attack order. Follow-player AI uses desired separation3000, three-second navigation cadence, locates player at range12800, and returns from combat beyond51200. Source catch-up teleports an escort beyond51200 to20000 behind the player; label this as the source escort assistance rule. Patrol scan cadence is7.5seconds, speed factor0.7, small patrol radius15000 and medium25000; medium police-style ships check legal status. Their combat routines otherwise use the selected project's borrowed O08 interceptor/flee behaviours. Defend units approach the main station to15000..20000 then engage; fix misspelled coliolis, undefined FLEE and ATTACK SHIP/ATTACK_SHIP state mismatches explicitly.

The original panel temporarily removes missiles to represent command buttons, requires several pylon slots and contains duplicated unit/Undo awards. Project adaptation presents a normal squadron command menu and never changes personal ammunition to render UI. This supports the owner's later hull switching and avoids inventing a six-pylon requirement for every ship. Existing unique equipment is transferred/stored by the shipyard contract; quest control access is commander-owned, not an extra refillable missile.

## Return, failure and persistence

Leaving the assigned system during an unfinished RUNNING mission sets that family's FAILURE and asks for a return to command; travel before reaching it is allowed. A pending mission may be aborted from the command menu. Success debrief adds earned points to friendly morale and subtracts them from opposing morale; failure/abort applies points-100 instead. Mission statistics add current kills/casualties and increment player plus all four unit mission counters in the source, including inactive units. Project keeps that source statistical rule separately from survival records. No deadline, direct credit payout or additional invented reward is required. Debrief unmarks the destination and clears transient counters exactly once.

Source ships are removed on docking and respawned on departure, which resets their damage/ammo; project saves each active pilot, hull, damage, energy, order, target, rounds, identity and whether it can follow the commander. Reload/jump restores one unit per slot and one mission encounter roster. Save mission family, assignment origin/destination, exact generated counts, target definition/identity, elapsed/completed flags, kill set, point snapshot, morale, pilot records and claimed debrief ID. Docking at an unrelated station cannot pay/complete command debriefs. Normal destruction/ejection follows the selected project save/death policy and cannot double-count casualties.
