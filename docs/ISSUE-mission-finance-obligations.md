# Shared monetary obligations need independent native custody

## Motivation and required behaviour

Existing credit commands and equipment loans do not represent shared monetary liabilities. Ordinary scripted dialogue requires an active instance and installed exact pack, so storing repayment only in that dialogue would strand accepted debt after parent completion or content loss. The accepted R06 first slice needs bounded fixed-principal offers, native explicit review, partial/final repayment, independent provenance and durable once-only receipts.

## Scope and compatibility

Use the existing Station Contracts page, single typed review slot, immutable Commander snapshot, sealed original-main arrival context, painted-page proof and synchronous save publication. Add no new screen, actor, mutable shared box or inline Commander review storage. Old saves without finance retain their original meaning; new finance state needs an explicit version so older formats cannot hide it. EMP conditional schema 22 and all its guards must remain compatible with ordinary 21 and finance 23.

The generic profile carries unpaid principal. Historical GSE short/zero-balance closure, defaults and facilities, full R06 interest/escrow and full P04/P19 are separate unfinished requirements. See [implementation and validation limits](PR-mission-finance-obligations.md).
