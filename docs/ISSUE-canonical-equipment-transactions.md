# Canonical equipment issue and ammunition transactions

Mission equipment and missile loading need to use the same physical inventory as native fitting, preserve original identities and provenance, and refuse stale or incomplete loan settlements before publication.

Provide pure sealed admission, fitting and settlement quotes over exact inventory, context, obligations and trusted budget snapshots. Fit-all retains each displaced actual device and records its original location. Return restores those same devices; release preserves the physical array while advancing the rights revision once. Historical original identities cannot be reused. Missing content never removes retained obligations.

Standard ammunition loading moves an actual held round. Finite consumption selects the highest occupied native pylon and returns the full removed item for the caller's mission delta. Unlimited use preserves all physical items and the revision. Native fitting of an active loan uses the issue-specific provider with its exact obligation.

A sealed read-only settlement projection shares the actual restoration planner so callers can derive cargo, equipment and accommodation budgets from the proposed items. Projection preserves the revision and carries no publication authority; quote and apply repeat all validation with trusted budgets.

The outer runtime remains responsible for atomically publishing the physical candidate, mission records, resources, events and ordnance. These helpers do not own mutable simulation state.
