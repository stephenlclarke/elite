# Own synchronous transaction scratch outside common dispatch frames

Private non-Sendable owners now retain only the temporary values that previously occupied transaction locals. Dispatch takes the same 64-event prefix, performs the same current-state preflight and evaluator call, then makes the original candidate Game and next-instance copies at the original post-evaluation point. Candidate, next, commands and derived events stay in the attempt owner. The common command loop/router passes references and indices; every native branch has a non-inlined leaf that owns its own call/result buffers. Training's early continue, every capability guard, optional-result append, encounter owner refresh, provider notification and original-snapshot standard command remain in order. Finalization/publication and self commit occur only after commands complete; typed refusal and generic failure paths preserve their original effects.

Acceptance preparation consumes its original completed instance into an owner. Its candidate copy still begins only at installation, with setup before accepted-event emission, suspension checking afterward and self commit last. Provider-state preparation returns before nested draining. Encounter scratch retains the original definition/geometry snapshot, plan/source/preparation and ready-path selected/staged instance values. Complete preparation reads still occur at their original boundaries. Retention staging returns before native commit, state publication remains after that commit, and the geometry defer restores the same snapshot on every unsuccessful exit. Pending/existing/unchanged cases and publication-flag order remain intact.

Owners exist only inside the synchronous GameRuntime turn or equivalent isolated Game value call. They are not stored in Game, serialized, cached, used as authority or captured in Sendable callbacks. Publication receives only the original inout Game. Selected values are consumed into ownership; Game/instance COW copies retain their original intent and independence. Game/Commander representation, Codable/Equatable, evaluator, validators, full comparisons, anchors, transaction writer and public mutation boundaries remain unchanged. Phase bodies and ordered command operations are checked against the original source with explicit same-value/inout substitutions and copy-point/rollback correspondence.

Existing regression inventory includes retention/source/admission refusal cases, populated/depth/malformed campaigns, acceptance disk failure, invalid-late-command rollback, result-queue exhaustion, native-result generation atomicity, replay and publication recovery. Tests are unchanged; this inventory does not request repeating already-qualified groups. Unaffected 18/19 groups retain their existing qualification; maintained full `make ci` is still required later.

Author validation is source correspondence, strict Swift formatting, Markdown lint and whitespace checks only. No author compiler/test/native/GUI/debugger/profiler/disassembly job runs. The source changes common ownership and dormant-buffer lifetimes; emitted allocation reduction, runtime stack margin, acceptance and complete CI remain unqualified until G1 execution.
