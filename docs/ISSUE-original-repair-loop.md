# Original repair-loop service

## Motivation

The approved W02 service needs an actual current failed unit, workshop operation and return to its original owner. A legacy equipment import, condition label or workshop visit cannot prove that the same original unit was repaired and returned.

## Approved scope

Carry one of six finite source-owned failed scoop-control units from Cedamar G01-S085 to the registered Celalen G01-S241 workshop, then return that serviced serial to its original Cedamar owner. The protected crate uses two tonnes and no berth. The ordinary H0 route pays 610 CR only on owner return: 430 base plus 90 for each of two legs. There is no deposit, workshop fee or deadline. Returned and lost units never replenish the batch.

## Acceptance

The station board shows the full loop, original serial, fault, transport-only permission and settlement terms. Separate fresh Confirm actions perform pickup, native repair and owner return. Back changes nothing. Live fitted hold, fuel and equipment facts govern admission; catalogue hull capacity is not a starting-fit guarantee. Existing native issue and return transactions retain serial and loan authority. Native repair changes that same failed item and creates a reciprocal service receipt. Only actual same-owner return pays and grants the repair-loop first-success clue. Shared capacity allows at most three combined Original/W01/W02 services. Failed publication preserves exact custody and actual losses remain lost.
