# Separate original emitted identities from native work timing

Legacy salvage removes saved current work after each release batch even when the section still has unreleased cargo. It does not retain original inspection or issuance timestamps. Its real issued allocator can prove which structural and planned chunks existed, but cannot prove that a current work budget is complete. Reconstructing legacy sources through AlienStorageWorldPlan would invent historical timing or reject genuine partial histories.

Extract a shared timing-free original seed/plan/allocator emission view for native validation and the legacy import validator. Keep strict native work/timestamp checks separate and preserve the original structural formula, mixed-unit chunks and serial identities. This supplies no native import, cutting, collection or fitting authority.
