| Status | Meaning |
| --- | --- |
| completed | The named capability is usable with observable evidence on an exact identified deliverable. Record its build/source and limits. Authored assets, fixtures, unit passes or unmerged source alone never qualify. |
| pending integration | A bounded implementation is prepared/reviewed and awaiting G1 composition; it is not yet delivered functionality. |

| not started | No implementation of this exact approved functional target is established. Designs/assets may be ready; shared engine code does not make its campaign playable. |

Delivery is a separate field: prepared branch; integrated source; verified local app; merged main; published release; published Homebrew. Record multiple locations when needed.
