# Shade the unlit hemisphere and show stable original settlements

FR034 requests an actual sunlit hemisphere, a dark hemisphere and a soft twilight terminator. Agricultural worlds should remain fairly dark at night; industrial worlds should show more light pollution. Technology and the ordered government classes increase bounded night brightness, with Anarchy substantially dimmer. These are fictional game art choices, not claims about real governments.

Keep daytime economy art direction independent of government. Use stable land settlement masks that rotate with the existing terrain, with clustered cities, coastal chains, sparse connecting corridors, cloud attenuation and modest local industrial haze. Avoid ocean, polar ice and high mountains. Flight lighting must derive from the actual current planet-to-sun vector in all four cockpit views; chart and data previews may use typed stable presentation lighting.

CPU and GPU must share profile interpretation, formulas and image identity. Mask generation, texture sampling and caches remain bounded and never consume simulation randomness. Coder 1 owns the actual Display light-source hook and all compiler, GPU, native, media and performance acceptance.
