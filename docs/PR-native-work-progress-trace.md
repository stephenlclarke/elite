# test(salvage): trace bounded native work progress on request

The remaining native multi-batch test can write at most six JSON lines directly to standard error, prefixed `ELITE_NATIVE_WORK_TRACE`, when its process environment contains `ELITE_NATIVE_WORK_TRACE=1`. The default path emits no trace. Each reached loop reports only at zero-based iterations 9 and 109, after its original work assertions, using its already computed before/after observations. The static phases are `first-release`, `second-cycle-start` and `resumed-release`. Observations contain seconds, releases, serial, pending count, damage and optional credited work; an absent optional credit is omitted by Swift's synthesized encoder. Monotonic elapsed time starts at test entry, including fixture preparation and intervening saves. Encoding failure emits a distinct error marker and supplies no progress evidence.
