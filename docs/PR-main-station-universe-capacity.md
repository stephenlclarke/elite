# Bound original main-station history to the complete canonical universe

NativeMainStationIdentity.maximumCount derives one finite maximum from 8 * (Plugh.systemID + 1), currently 2,056. The actual original-main registration resource/identity/observation checks, both NativeStationWorld validation counts, both arrays' initial decoded-count and streaming element checks, and ScriptEngineState's main-resource semantic count use that shared limit. These are the only production changes, confined to NativeStationAdmission.swift, NativeStationRuntime.swift and ScriptWorldJobState.swift.

All uniqueness, canonical resource identity, commander owner, system/galaxy domain, observation actor/calendar, pose/source authenticity, immutable history, receipt and counter rules remain unchanged. No eviction or reset is added. The separate RRS catalogue remains 372 and its producer systems remain 0..<256; unrelated job/text/counter limits are unchanged. Resource dictionaries keep their existing synthesized decoding and semantic validation. The original-main arrays still reject over-budget counts before decoding invalid children, and still enforce a streaming bound when container counts are unavailable. No save fields, format version or file-byte limits change; older sparse and missing-optional-array representations remain readable. Older binaries retain their own stricter historical count policy.

## Authored regressions

Five source-authored methods include seven parameterized cases. A controlled historical fixture retains the original real observation/resource and every RRS record, pose, counter and owner, then adds canonical historical identities without manufacturing service/arrival receipts. Two 257th-location cases select PLUGH in galaxy zero or an ordinary system in galaxy one in the private fixture; actual Game.launch loads the original station body and calls the real registration boundary. They check the new actor/resource and preserved earlier histories, owner/counters, no minted docking receipt and repeat registration idempotence. Initial fixture location selection is not a claim of actual intergalactic hyperspace travel.

The complete 2,056-location case checks every canonical identity/resource, immutable RRS ownership/history, exact Codable round trips, then actual versioned runtime save/read/load retaining all original-main histories and resources. Negative cases cover 2,057-entry arrays rejected before invalid child decoding, invalid children still rejected at the accepted count, duplicate identities/observations/resources, foreign owners, invalid galaxy/system and oversized resource semantics. Existing 256-entry histories and older missing optional arrays remain readable without changing RRS state or counters.
