# PR 107: bounded physical adoption lifetimes

Physical adoption keeps the original visit/system entry and flight snapshot, then iterates the same body indices. A separate eligibility frame owns one body projection and checks its three optional tags in the original order through a borrowing helper. Ordered `case .none` checks replace comparisons against nil, preserving their result without optional equality argument payloads. That projection ends before a separate helper runs the original main-station identity, live actor allocation, failed-identity return and physical-state construction/assignment. Returning from the helper continues the outer iteration, as before.
