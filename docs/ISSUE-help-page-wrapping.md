# Help text can exceed the compact viewport

The complete catalogue test found help rows longer than the supported 40-character width. New mission and targeting instructions must remain readable with the fixed small font in windowed and full-screen views.

Acceptance requires every help row to fit 40 characters, every page to fit 16 rows, all instructions to remain present, and help navigation and pause behaviour to remain unchanged. See [implementation and validation](PR-help-page-wrapping.md).
