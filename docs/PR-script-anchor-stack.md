# Borrow script anchor inputs and separate persistence lifetimes

`ScriptEncounters.swift` replaces anchor selection's whole-Commander fallback accesses with one non-inlined static resolver taking explicitly borrowed bodies, reference frame and Commander. First-index selection preserves the original first-station behavior while avoiding the optional actual-body temporary. The existing `scriptAnchor` property delegates to this resolver; persistence calls it directly without a Game value receiver.

`persistScriptActors` retains its initial empty-instance guard, then calls a non-inlined mutating station-refresh helper containing the original station update body. Once that helper returns, it resolves the anchor, persists shots and calls a non-inlined mutating actor-capture helper with a borrowed anchor. The original unloading/removal, actual-body dictionary and full instance/encounter/actor capture body are unchanged. Station loss and frame refresh still happen even if the anchor is refused. All external publication and rollback code remains untouched.

`ScriptAnchorPersistenceTests.swift` adds seven read-only selection cases plus actual mission-admitted actor cases for live/saved anchors, canonical pose/velocity retention, unloading and dead-station refresh/refusal. It uses the existing catalogue/mission fixture, without inventing native actor authority. The unchanged original durable timer and failed-writer regressions, EMP archive nested timer cases, station-loss/condition tests and existing projectile/actor retention tests remain part of G1's focused qualification.

Strict source formatting, whitespace checks and exact token correspondence for both extracted persistence bodies are the worker's validation. No compiler, build, test, native, GUI, renderer or debugger job was run.
