# Add deterministic sparse rings and conserved native-unit chunks

AsteroidBeltDefinition supplies one deterministic presence, chunk quantity and composition contract. A ring is centred on the actual canonical sun at twice the actual sun-to-planet distance. Its plane contains that radial direction. Three widely separated sectors contain four rocks each, with centres within 35 native coordinates of the ring radius. Unsafe candidates are omitted; no alternate planet shell is substituted. Chunk radius and hit points scale with the cube root of quantity. All eleven quantities appear in a complete safe ring. Lave is an authored starting mining destination; other systems have a seeded 75% presence probability. These density, thickness, durability and content proportions are explicit project balance choices, separate from the requested ring and quantity contracts.

New ring identities use fields 4 through 7 and a separate 48-bit ringTerminal mask. The frozen legacy generator, fields 0 through 3, old 48-bit depletion and old canonical yields remain intact. Fresh ledgers carry generation 1 and use rings only. A decoded old ledger with no generation marker retains its old clusters alongside rings; a missing old ledger has no mining history and safely uses fresh defaults. New ring activity preserves the legacy flag. Existing salvage-site generation explicitly uses the frozen legacy fields to preserve source identities and positions.

Each ring chunk produces exactly its declared number of uniquely identified unit cargo payloads of its deterministic content: minerals, alloys, gold or platinum. Units are the commodity's native market units, tonnes for minerals/alloys and kilograms for precious metals, not a new conversion between mass and radius. Pending output retains the existing 256-payload bound and admission quotas. Insufficient capacity refuses the entire final extraction before damage, depletion or incident mutation. Reload validates new fragment identities against the same identity-derived manifest; it never uses placeholder geometry as quantity authority. Legacy payload quantities and motions are unchanged. Departure continues to expire abandoned pending ore while keeping permanent depletion.

Both charts show cyan oval belt markers and a legend without replacing economy/government/technology colours. System details show belt presence, ring rule, chunk units and the authored ore palette. Remote galaxy lookup uses the viewed/inspected galaxy. MiningRockAppearance provides ore materials without changing scaled geometry or orange target classification; white wireframe remains governed by the existing renderer. NPC miner planning already calls the shared MiningFields generator. The central integrator owns the narrow scene, material/wire-colour and save-header hooks described below.
