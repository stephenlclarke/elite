# NPC front beams track target centres inside the acquisition cone

`prepareGameplayNPCBeam` admits near-forward targets with a dot product above 0.98, then casts its collision ray directly toward the selected target centre. The path has no mounted gimbal or aim-assist entitlement, so that acquisition cone grants unearned steering around the physical front axis and defeats off-axis evasion.

Use the normalized forward axis for the existing native nearest-obstruction query. Preserve selection, range, intended-target admission, finite turning, resource gates, attribution and law. Validate aligned hits, a target-centre hit that the real forward ray misses, and a nearer obstruction through maintained combat fixtures.
