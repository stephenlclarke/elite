# Authenticate structural and native companion custody

Adds a typed companion world record for actual structural debris and non-reserved original-plan chunks. A structural origin or original item index plus chunk ordinal is distinct from the emitted lot serial. A shared pure native producer reconstructs exact quantity, content, mass, bounds, value, provenance and legality; the ordinary cutter delegates only its existing chunk/structural construction to this helper. Original progress, serial allocation, source selection and ordinary capacity rules are unchanged.

The world validator derives the actual emitted set once per plan and requires exactly one reserved or companion custodian for each serial. Reserved planned technology still has explicit unissued/discarded state; attachment sources remain exclusive to the eight reserved definitions. Companion pending state retains physical time and unique offers/bindings shared with reserved lots. Permanent collection evidence records the operation, collector hull, time and either exact commodity before/after quantities with checked arithmetic or an independent owned native-technology storage identity. Missing/duplicate emissions, altered chunks, mismatched content, unrepresentable vector lengths, duplicate collection operations/storage, backward time and terminal rewrites refuse. Companion records use the existing authenticated world pages, with no new lifetime count cap or monolithic history array.

The original producer tests now retain structural companions and all commodity/native technology chunks; plan-only snapshots with missing emitted custody are refused. New focused tests compare genuine native emissions, page round trips, typed collections, overflow/content/origin tampering and terminal preservation. Formatting and source review precede compilation; actual focused execution is pending at this checkpoint.

This change is a durable custody foundation. It does not yet implement actual pre-cap inspection/cutting, collector permits and hold refusal, atomic live cargo/technology publication, native save hydration, real PLUGH dock/fitting authority or alien effects. Pure storage receipts do not claim those native actions occurred. Existing saved storage without structural companions is rejected rather than inventing lost history; the normalized store has not yet been published as a commander save schema.
