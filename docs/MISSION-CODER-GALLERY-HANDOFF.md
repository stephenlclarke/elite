## Required behaviour

1. Campaign details show an Assignments section from actual native child declarations/bindings. Each row identifies the human title, objective and actual status. Distinguish Not started, Active, Complete, Failed, Abandoned and Suspended, retaining the suspension reason. Never infer child success from a parent's milestone count. Missing exact content stays identifiable and unavailable.
2. Selecting an existing assignment opens that exact saved child's detail row. Two parents using the same template must navigate to their different actual child instances. A declared but unstarted assignment may show a read-only preview and explicit unavailable reason; browsing must never call `child.ensure`, accept a pack or mutate a saved mission.
3. Child details say `Part of {campaign title}` and provide View campaign to the actual immediate owner. Preserve navigation Back/scroll context. Nested children retain the immediate-owner relationship and resolve the correct root separately for trials. Titles are presentation; UUIDs and exact pinned content determine identity.
4. An owned-child action is Try campaign. It reviews/selects the exact owning root campaign's supported trial and starts it only on the existing deliberate trial action. It never restarts a live child, launches it standalone or changes its outcome. Missing root content, unsupported capabilities/prerequisites or an existing trial produce explicit unavailable reasons. Do not weaken `parentOnly`, save namespaces or the normal `canTrialSelectedMission` checks to implement routing.
5. Trial context remains visible: `Trial - live commander unchanged`. The fresh root trial follows actual launch/combat/docking/report/debrief, and Save/Load/Restart/Return retain the existing isolated commander, resources, calendar, file namespace and input epoch. Browsing a live campaign never changes its cash, actors, people, stock, receipts or jobs.
6. Use existing Gallery controls and normalized navigation, with matching pointer/keyboard actions. Keep the fixed logical font. At512x518 and1512x982@2, readable content scrolls and the action band stays outside text/HUD; no clipped or unreachable relationship/trial controls. Preserve existing Gallery list/detail navigation, retry and noncampaign trials.
