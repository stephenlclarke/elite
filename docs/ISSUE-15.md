# Install the published release through Homebrew

## Motivation

The newly published Elite 1.4.0 GitHub Release must be installable through Homebrew, and the README must explain both installation methods with working download links.

Synchronize the maintained cask and public tap to the actual versioned Release asset and exact SHA-256, retaining protected-main artifact provenance, universal macOS 14 support, quarantine, saves and mission packs.
