# Draw native-resolution graphics and continuous stars

## Behaviour

Ships, planet curves, stars, chart points and cockpit geometry now draw directly into AppKit's Retina-aware window context. The ordered drawing commands keep floating-point geometry until presentation. Exported images use the same path at any supported pixel size, including sizes that are not multiples of 256. Text retains the original bitmap glyphs and nearest-neighbour scaling above the geometry.

A persistent deterministic starfield belongs to the game actor's value state. Its stars share the ships' translation, pitch, roll and view transforms. Small antialiased circles replace large pixels and fixed diagonal tails. Throttle changes affect subsequent movement rather than repositioning the sky from elapsed time. Stars recycle at bounded distances without increasing the population. Hyperspace rings also retain fractional radii.

## Validation

Two native regressions failed before the fix and pass afterward: planet antialiasing and unchanged space pixels when throttle changes without a simulation tick. Additional tests check exact export dimensions, original font pixels, stationary stars, frame-rate-independent travel, shared camera rotation, all four views, help pausing and long-running bounded recycling. Existing ship silhouette and shaded-face tests remain in place. `make ci` supplies coverage, thread/address sanitizers and the native leak lifecycle probe; committed main supplies the authoritative Sonar scan.

The native app is inspected in flight at normal and full throttle, including window resizing. README media is regenerated by the game renderer.

Local validation passed with 38 tests, 93.35% line coverage, clean thread/address sanitizer runs and zero detected leaks. Native export checks include 1379-square resizing and 3072-square output, while font checks preserve each original glyph pixel.

Native AppKit tests run sequentially because they share one application and event loop. This prevents large export checks from delaying the window's first frame during sanitizer validation; the startup assertion and its bounded wait remain in place.

## Compatibility

This is an intentional display improvement over the historical BBC renderer. Commander saves, game rules and keys are unchanged. Star positions are transient simulation state, not a commander-save format change. The deterministic low-resolution raster remains available for core rendering tests; normal play uses native drawing.
