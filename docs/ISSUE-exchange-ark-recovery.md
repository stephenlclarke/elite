# M10.P02.C08.recovery: finite consented replacement after actual destruction

The normal seed-ark receiving path must also honor the authored no-payment destruction recovery. A vanished actor, reset source, copied original hull or replenished bank cannot provide that recovery.

The explicit authoring decision supplies exactly one initial reserve per induction: one separate SH061 hull, forty distinct seed-tonne units, six distinct living crew and its own 1,000-CR fuel issue. Consume it once through real Enlirin custodian rebrief/consent after proved prior-ark destruction, with the same original key still held. Retain original losses and purchases, return unused old escrow only to the custodians, preserve shared station fuel depletion and refuse further launches after reserve consumption. A lost key needs actual authored recovery, with no newly minted key.
