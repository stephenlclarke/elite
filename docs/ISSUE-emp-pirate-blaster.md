# EMP disablement, occupied crew custody and shared target colours

The requested electronic weapon must disable a real ordinary ship without destroying it, preserve momentum and legal aggression, and expose that same hull to salvage only after its actual human complement has ejected. Crew must never become sale cargo or duplicate across actor-capacity refusals, save/load and re-entry. Existing lasers, mining/salvage fittings and finite loot must retain their own ownership rules.

HUD, target details and world cues also need one classification: hostile red takes precedence; otherwise disabled and genuinely mineable or salvageable objects are orange, including unselected objects and every display mode. Decorative rocks remain ordinary and white-wireframe geometry stays white.

See [implementation and pending validation](PR-emp-pirate-blaster.md). No GitHub issue or PR has been created for this isolated draft.
