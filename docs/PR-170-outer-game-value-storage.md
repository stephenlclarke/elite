## Implementation

Move all159 original stored fields into one private Sendable Values payload behind a single-element Swift Array. Preserve every stored default and declaration order, public/internal/private visibility and field type. Forward reads and nested mutation through synchronous `_read` and `_modify` accessors; Swift Array detaches shared values before mutable yield. Existing Commander and child-state CoW storage remains in the payload. A new Game alone initializes original defaults; array detachment copies existing values without creating fresh UUIDs, RNG state or universe defaults. An explicit empty Values initializer prevents a synthesized159-argument defaulted memberwise construction API.

The runtime epoch accessor writes its original field and performs the same ten dependent resets in the original order. Its inout accessor stages only the UUID and writes it through that setter on return, including unchanged inout writes, avoiding overlapping mutation of the outer array while resetting sibling fields. The original Game initializer body and computed market/ECM/current-system APIs remain intact. GameRuntime continues to own the Sendable Game value; there is no shared mutable Game class or unchecked Sendable conformance. Synchronous pointer readers keep their original nonescaping scopes. Commander remains the Codable save boundary; no runtime payload enters saves.
