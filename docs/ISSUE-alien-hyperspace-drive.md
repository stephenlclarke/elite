Complete one physical route: a deterministic alien-only salvage outcome, authenticated collection into the existing owned alien inventory, explicit fitting at the real PLUGH main-station doorway, then immediate hyperspace without hyperspace mass lock. Stored, retired, foreign and other-hull items must confer no capability. Ordinary drive, range, fuel, electrical-disable and in-system jump gates remain effective.

Reuse the existing page-tree source, ownership, fitting and save transactions. The drive has a distinct typed effect and no scalar bonus or upgrade recipe. Historical save compatibility is outside this assignment by the current project instruction.
