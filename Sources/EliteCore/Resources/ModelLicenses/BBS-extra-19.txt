Z GrOovy Binary Basic Panther Clipper {1.0} 15-Feb-2014

*** Contents ***

- Panther Clipper

This is the binary basic Panther Clipper, with adapted oolite specs in order to preserve gameplay.

You can no longer change the color alas, since now random coloring by shader has taken over that work, you will have to wait till you see a color scheme you like at your favorite shipyard.
However you can choose whether you want the vibrant colors or the regular ones. Install one of the two files, not both. See screenshots included for differences.

This ship is slow, but can pack quite a punch. Watch out when attacking these behemoths. You have been warned.

Have fun!

*** Dependables/Requirements ***

This oxp is standalone, as will be all next upcoming ships. I will be adding all ships to a single file though, so the next time a ship is released, the adder will again be in the zip. Please copy both files again to your addons folder, as I might have done updates on previous ships. 

*** Installation ***

Delete any previous files with the same name and install this one when updating to a newer version.
As always, copy the OXP to the addons directory and while starting up Oolite hold the SHIFT key until you see the spinning cobra.
